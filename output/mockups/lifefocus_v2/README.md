# DopaBreak — 画面モック v2（E1 "Dark Mono"）

SNS依存から人生の時間を守るアプリ「DopaBreak」の全画面モック（**全29画面**・23_post_reflection含む）。確定アートディレクション **E1 Dark Mono**（Oura / Linear / Whoop 系の冷たい規律・1アクセント）で統一。

- 解像度: 全画面 **1206×2622px**（iPhone 16 Pro 論理402×874pt @3x / Chrome headless）
- 実装: HTML/CSS（1ファイル＝1画面）。Google Fonts: Zen Kaku Gothic New / Space Grotesk / JetBrains Mono
- 仕様書: `../../../design/BUILD_SPEC_E1.md`
- 再生成: `./render.sh`（各HTMLを1206×2622 PNG化）

## デザイントークン
- 背景 `#0A0B0D` / カード `#14171C` / 主テキスト `#F4F5F2` / 副 `#7E8694`
- 唯一のアクセント: electric lime `#C7F94D`（各画面で1役割に限定）
- hairline divider `rgba(255,255,255,.08)`

## 機能の主従
- **ヒーロー＝人生の目標表示**（ロック画面ウィジェット＋介入時に常時想起）。マーケ/ASOの差別化点。
- **エンジン＝SNSゲート**（一呼吸→使用量→意図→時間→結果→再介入の日次介入フロー）。
- 目標は軽量に留める（タスク管理・期限・チェックリストは持たない）。

## オンボーディング設計（顕在化→価格）
one secのPHQ型自己診断を踏襲しつつ、効果の約束（景表法グレー）を避け「本人の回答からの推計損失」を提示する顕在化フロー。
1. **約束**（01）損失回避コピー「人生の時間は二度と戻らない」。
2. **自己診断**（02 / 02b / 02c）開く頻度＋目的なきスクロール＋後悔をPHQ型頻度で問い、悩みを言語化。
3. **推計損失リビール**（03_quiz_result）回答から「1日2.5時間＝年38日」を突きつける感情のピーク。`※ご回答からの推計値です。医療診断ではありません。`
4. **設定**（03 choose_apps → 04 goal → 05 mode）と**信頼**（06 予告 → 06b 科学的背景）。
5. **専用プラン要約**（08b）アプリ数/目標/推計38日を再提示しサンクコストを作る → ペイウォール（22）。

## アニメーション（モーションプロトタイプ）
HTML/CSSアニメをChrome headlessでフレーム連番化し、ffmpegでMP4/GIF化（各HTMLは `?t=<ms>` で任意時刻に凍結してフレーム取得）。

| ファイル | 内容 |
|---------|------|
| anim_welcome.mp4 / .gif | Welcomeヒーロー：グロー開花→集中ゲージ自己描画→見出しのマスクせり上がり→CTA |
| anim_intervention.mp4 / .gif | 介入の瞬間：カーテン上昇→退去でブレスリング出現→3-2-1呼吸→**目標フェードアップ**→意図ボタン |
| anim_onboarding_flow.mp4 / .gif | オンボ遷移ウォークスルー：横スライド＋進捗バー（01→03→04→06b→09） |
| anim_*.html | 上記の動く実体（編集可） |

実装メモ：iOSではアプリ起動をDeviceActivity/Shieldで検知。Shield Configuration Extensionは静的UIのみ可のため、本フルアニメは「Shieldの軽い静止画→タップで自前アプリに遷移して本番アニメ」の二段構えで再現する。

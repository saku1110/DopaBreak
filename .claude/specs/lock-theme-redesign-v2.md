## 2. フォント方針

| テーマ | 日本語・英語 | 韓国語 | 調達 | サイズ |
|---|---|---|---|---|
| ゲーミング | DotGothic16 | **Galmuri11** | バンドル（SIL OFL） | 2.0 / 5.13 MB |
| 手書きノート | Zen Kurenaido | **Nanum Pen Script** | バンドル（SIL OFL） | 4.1 / 3.05 MB |
| レトロポップ | ヒラギノ丸ゴ ProN W4 | 同左（ハングルはシステムへ委譲） | iOS同梱 | 0 |
| かわいいピンク | ヒラギノ丸ゴ ProN W4 | 同左（ハングルはシステムへ委譲） | iOS同梱 | 0 |
| 上記以外 | システムフォント（`.system`） | 同左 | — | 0 |

**合計バンドル増分: 14.26 MB**（オーナー決裁 2026-08-26）

### 韓国語フォントを追加した理由（2026-08-26 オーナー決裁）

DotGothic16 と Zen Kurenaido は **ハングルのグリフを1文字も持たない**（CoreTextで実測確認）。
豆腐にはならず Apple SD Gothic Neo へフォールバックするが、**1行の中で書体が混ざる**。
実測例: ゲーミングの韓国語「30분 독서하기」は「30」だけドット絵で「분 독서하기」は普通のゴシック。
ドット絵・手書きというテーマの identity が韓国語では成立しないため、韓国語専用の代替書体を追加する。

- **Galmuri11**（5.13 MB・SIL OFL 1.1・埋め込み明示許諾あり）: ハングル・ラテン・数字・`×` を完備。ゲーミングの韓国語用
- **Nanum Pen Script**（3.05 MB・SIL OFL 1.1）: ハングル・ラテン・数字・`×` を完備。手書きノートの韓国語用
- 両フォントとも Latin と数字も持つため、**韓国語ロケールでは行全体を代替書体で描く**（混植しない）
- レトロポップ・かわいいピンクの `HiraMaruProN-W4` もハングル非対応だが、落ち先が同系のゴシックで違和感が小さいため追加しない

### バンドル要件
- **アプリ本体とWidget Extensionの両方から参照する**（Live Activityは拡張プロセス、設定のプレビューは本体プロセスで描画されるため）。
- **フォントの実体は1コピーに留めること**。現行方式はアプリターゲットの resources build phase へ .ttf を直接同梱し、Widget は親アプリバンドルから登録する（§4.4の注記参照）。
- ファイル未登録・登録失敗時は**必ずシステムフォントへフォールバック**してクラッシュ・豆腐表示を出さないこと。
- ライセンス表記: 設定「このアプリについて」のライセンス欄に4フォント分の SIL OFL 1.1 の記載を入れる。
- 書体の切り替えは**表示ロケール基準**で行う（目標タイトルの文字種で判定しない。ユーザーが韓国語UIで日本語の目標を書く等の混在があるため）。

## 1. プロダクト概要

GoalGateは、ユーザーが対象アプリを開こうとした瞬間に介入し、深呼吸、使用状況、目標表示、意図確認、必要時間の選択を通じて、無意識スクロールを意図的な利用へ変えるiOSアプリである。

ホーム画面/ロック画面ウィジェットでは、SNSを開く前に思い出したい短い戻る先を常時表示する。

DopaBreak版では、SNS依存改善に絞る。対象SNSを開く前に一呼吸と意図確認を入れ、必要時間だけ開放する。さらに、利用後に「SNSを見てどうだったか」を質問し、満足感や幸福感の変化を記録する。

重要な実装前提:

- iOSでは、他社SNSアプリを閉じた瞬間を完全に検知することはできない。
- 利用後リフレクションは、選択時間終了時、再シールド時、DopaBreak復帰時、または通知で近似する。
- ユーザー向けには「閉じた瞬間に必ず出る」と表現しない。

## 2. 参考フローと独自フロー

### 添付画像の参考フロー

1. 対象アプリを開く
2. 深呼吸を促す画面が出る
3. 24時間以内のオープン試行回数と最終利用時刻を表示
4. 開かない/続けるを選ぶ
5. 開く場合、必要時間を選ぶ
6. 指定時間だけ対象アプリを開く

### GoalGateの独自フロー

1. 対象アプリを開く
2. 一呼吸画面を表示
3. 今日の目標/戻る先を表示
4. 「なぜ開く？」を選ぶ
5. 選択理由が目標に沿うか確認
6. 必要時間を選ぶ
7. 指定時間だけ開放
8. 時間終了後、再介入または利用後リフレクション
9. SNS後の満足感、得られたもの、幸福感の変化を記録

差別化は `意図確認` と `利用後リフレクション` である。

## 4. 主要ユーザーフロー

### Flow A: 初回セットアップ

1. Welcome
2. 目的選択
   - SNS時間を減らしたい
   - 勉強/仕事に集中したい
   - 目標を忘れたくない
   - 夜のSNSを止めたい
3. 目標作成
4. 対象アプリ選択
5. Screen Time権限許可
6. 介入スタイル選択
7. ウィジェット追加ガイド
8. テスト介入

### Flow B: 対象アプリを開こうとする

1. 対象アプリをタップ
2. シールド画面表示
3. 一呼吸カウント
4. 使用状況と目標カード表示
5. 意図確認
6. 必要時間選択
7. 一時開放または終了

### Flow C: SNS利用後に振り返る

1. 選択時間が終了する、または再シールドされる。
2. 利用後リフレクションを表示する。
3. 「SNSを見てどうだった？」に回答する。
4. 満足度と、満足度から導出した幸福感変化を記録する。
5. 必要に応じて「閉じる」「あと1分だけ」「次から強める」を選ぶ。

### Flow D: 開くのをやめる

1. 「開かない」を押す
2. 成功フィードバック
3. 代替行動を1つ提案
4. 記録
5. 元の画面へ戻る

### Flow E: 週次振り返り

1. 開こうとした回数
2. 止まれた回数
3. 理由別内訳
4. 利用後の満足感内訳
5. 幸福感が増えた/変わらない/減った比率
6. 取り戻した推定時間
7. 来週の重点時間帯提案

## 8.1 利用後リフレクション

目的:

- SNSを禁止するのではなく、使った後の実感を自分で観察させる。
- 満足感が低いSNS利用を可視化し、次回の自発的な抑制につなげる。

トリガー:

| トリガー | MVP対応 | 備考 |
| --- | --- | --- |
| 選択時間終了時 | Must | 最も現実的。再シールドと同時に表示 |
| DopaBreak復帰時 | Should | 直前に開放したセッションがある場合だけ表示 |
| 通知 | Should | 閉じた瞬間ではなく数分後の振り返り |
| SNSを閉じた瞬間 | Won't | iOS公式APIでは直接検知できない |

質問（1問）:

```text
SNSを見てどうだった？

[満足感があった]
[楽しかった]
[何も得られなかった]
[時間を失った感じがする]
[気分が下がった]
```

選択した満足度を1タップで保存してシートを閉じる。幸福感変化は満足度から導出して同時に保存する。

## 9. ウィジェット仕様

### Small

- 目標1行
- 今日の止まれた回数

### Medium

- 主目標
- 今日の止まれた回数
- 利用後リフレクション未回答数
- Deep Focus状態

### Lock Screen

- 短い目標を複数配置
- 1ウィジェットあたり1目標の小型配置を基本にする
- `accessoryRectangular` では、1つのウィジェット内に2-3件までまとめて表示できる
- 目標は最大12-16文字程度に短縮
- 大きなカードではなく小型チップ/短文表示
- ユーザーは表示する目標と順番を選べる
- 止まれた回数

初期レイアウト:

```text
[英語で話す] [深く集中] [夜は見ない]
```

1つの矩形ウィジェット内に複数表示する場合:

```text
[ 英語で話す ]
[ 深く集中 ] [ 夜は見ない ]
```

設計ルール:

- Freeはロック画面目標ウィジェット1個まで。
- Proは複数配置を許可する。
- 1件表示は大きめの文字、2件表示は中サイズ、3件表示は小サイズに自動調整する。
- 4件以上を1つのウィジェットに詰め込まず、上位3件と「+N」で省略する。
- `accessoryInline` と `accessoryCircular` は原則1件表示にする。
- タスク、期限、チェックリストは表示しない。
- 長い目標は自動で短縮候補を作る。

## 10. 統計仕様

表示する指標:

- 今日の開こうとした回数
- 開かなかった回数
- 開いた回数
- 理由別内訳
- 利用後リフレクション回答率
- 利用後の満足感内訳
- 幸福感が増えた/変わらない/減った比率
- 「何も得られなかった」SNS時間の割合
- 対象アプリ別内訳
- 時間帯別傾向
- 推定で取り戻した時間

MVPではオンデバイス集計を原則とする。

## 11. プライバシー仕様

- 対象アプリ選択はScreen Time APIのトークンを使う。
- 原則としてアプリ使用詳細をサーバへ送らない。
- 分析イベントは個人の対象アプリ名を含めない。
- 目標、理由ログ、利用後リフレクションは端末内保存を基本にする。
- クラッシュログに目標文やアプリ名を送らない。

## 12. 成功状態

MVPのプロダクト成功は、ユーザーが以下の状態になること。

1. 目標がホーム/ロック画面に表示されている。
2. 少なくとも1つの誘惑アプリに介入が入っている。
3. 1日に複数回、開く前に意図確認している。
4. SNS利用後に「本当に満たされたか」を記録できている。
5. 週次で「止まれた」だけでなく「何も得られなかったSNS時間」が見えている。
6. 制限ではなく、気づきによって自分で減らす体験として受け取っている。

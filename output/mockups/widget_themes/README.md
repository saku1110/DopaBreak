## 生成モデル比較（nanobanana 2 vs 2 Lite・各テーマ同一JSONプロンプト）

| | `gemini-3.1-flash-image`（nb2_*.png） | `gemini-3.1-flash-lite-image`（nb2lite_*.png） |
| --- | --- | --- |
| 日本語テキスト | ◎ 正確（「英語で話す」「今日7回止まれた」とも崩れなし） | ◎ 正確（同等） |
| iOSレイアウト再現 | ◎ 端末フレーム・時計→ウィジェットの配置が実機に忠実 | △ ステータスバーの二重描画・ウィジェット位置が実機とズレる |
| テーマ表現 | ○ 上品だがアクセント控えめ | ○ アクセントが乗りやすい（時計に琥珀色など） |
| 破綻 | ほぼなし | フレーム外への要素複製あり |

**結論: 資料・ストア用途のモックは標準版（gemini-3.1-flash-image）を採用。Liteは案出し（数を打つムード探索）用**。日本語文字品質は両者とも実用レベルで、旧世代（Nano Banana初代）の「日本語が崩れる」問題はほぼ解消している。単価はLiteが下位ティア（最新の正確な料金は要確認）。

# 事業設計

作成日: 2026-06-27 / 改訂: 2026-07-02（GoalGate表記の除去・目標ヒーロー軽量版へ統一・価格確定・競合データ更新）

## 1. 事業仮説

**DopaBreak（2026-07-02正式決定・旧仮称LifeFocus → 経緯は docs/09 §5）** は、SNSや動画アプリを開く直前に「本当に今開くべきか」を問い、使った後に「見てどうだった？」を振り返らせるiOSアプリである。

既存のスクリーンタイムアプリは「使わせない」ことが中心である。本アプリは、禁止ではなく**意図確認と利用後リフレクション**で、自分からSNSを減らしたくなる状態を作る。

構造は二層（確定方針・目標ヒーロー軽量版）:

- **目標表示＝ヒーロー（看板/マーケ主役）**: 人生の目標1つ＋1年の目標1つだけを、ロック画面ウィジェットと介入時に表示する。タスク管理化しない。
- **SNSゲート＝エンジン（日次の実用機能）**: 一呼吸→意図確認→必要時間だけ開放→利用後リフレクション。

中核価値は、SNSを開く前に止めることと、SNSを使った後に「本当に満足感があったか」を自分で観察させ、自発的に開く回数を減らしたくなる状態を作ることである。

## 4. ターゲット

### Primary ICP（2026-07-02 オーナー確定）

**SNS依存・ドーパミン中毒を自覚するiPhoneユーザー全般（20-39歳中心）**。特定の属性層に絞らず、「依存が人生（時間）を無駄にしている」という**損失回避の心理**を軸に訴求する。競合多数のため、訴求の差別化は「禁止しない」×「見た後の正直な気持ちの可視化」×「ロック画面の戻る先」で行う。

心理:

- 意識は高いが、毎日意志力で勝ち続けるのは難しい。
- 気づいたら2時間溶けていた自己嫌悪をなくしたい。
- スマホ依存対策はしたいが、完全ブロックは挫折した/続かない。
- 使った後の虚しさや集中力の低下を自分で認識したい。
- 意志が弱い自分を責めずに変わりたい。

## 5. Jobs To Be Done

1. SNSを開こうとした瞬間に、自分がなぜ開こうとしているのか気づきたい。
2. SNSを見た後に「本当に満足だったか」を正直に確かめたい。
3. 完全に禁止せず、必要なときだけ短時間使いたい。
4. スマホを触るたびに、戻る先（人生の方向性）を思い出したい。
5. 無意識に開いた回数や、踏みとどまれた回数、失った時間を見たい。

### 価格の根拠（収益最大化）

1. **競合レンジとの整合**: 差別化アプリはJomo $29.99〜Roots $59/年で成立している。旧モック価格の¥2,400/年はone sec（単機能・$19）対抗の最安帯であり、「摩擦＋リフレクション＋ウィジェット」の複合価値と矛盾する。安売りは差別化の自己否定。
2. **ユニットエコノミクス（2026-07-11改訂: 更新率想定を60%→40%へ引き下げ）**: 年額¥4,980 × App Store手数料15%（Small Business Program）＝手取り約¥4,230/年。旧想定の年次更新率60%はSOSA実測でP90（上位10%）水準であり計画基準として危険（年額1st更新の業界中央値は25.2%）。**計画基準はQ3水準の1st更新40%**（2nd 60%・3rd 70%）とし、期待LTV≒**¥7,700**。月100万円利益に必要なアクティブ有料会員は約2,800人で不変（月あたり手取り¥353換算）だが、更新率40%では**毎年約1,700人の新規獲得補充**が必要（60%想定なら約1,100人）。感度: 中央値25%ならLTV≒¥6,200 / P90の60%ならLTV≒¥10,500。→ 3段シナリオの詳細は docs/15 §7。
3. **獲得チャネルとの整合**: LTV:CAC 3:1を守るとCAC許容≒**¥2,550**/paid（LTV¥7,700基準）。DL→有料4%想定でCPI許容≒**¥100**となり、**広告単独では回らない→ASO/SEO主導＋広告は勝ちクリエイティブのみ**という戦略（doc02）は旧想定（CPI¥140）よりさらに強く成立。価格を上げる・更新率を上げるほど許容CPIが上がり、チャネルが広がる（更新率60%を実証できたらCPI上限を¥140へ戻す）。
4. **A/B前提**: ローンチ時に年額 **¥3,980 vs ¥4,980** の価格テストを実施。StoreKitは表示価格を動的に変えられないため、**年額製品を2本用意**（`dopabreak.pro.annual` = ¥4,980 / `dopabreak.pro.annual.launch` = ¥3,980）し、どちらをペイウォールに表示するかをリモート構成で出し分ける。転換率の差が25%未満なら¥4,980を採用し、もう一方を販売停止。

### ペイウォール構成（→ doc06 P-01 / paywall-optimization・docs/15 §3.3準拠）

- **2段表示（2026-07-11改訂）**: **Annual（「一番人気・一番お得」バッジ・デフォルト選択）** → Monthly。業界標準は2プラン（3+は選択麻痺リスクの少数派）。Lifetimeはペイウォール常設から外し、設定画面と年額解約フロー（win-back）で提示。
- 日本版は長文・情報量多の縦長構成（機能リスト・課金タイミング明示・解約手順・FAQ）＝日本市場で+20%の実測。米国版は簡潔に別設計（transcreation）。
- **7日無料トライアル→「失った時間レポート」を先に体験させてから課金**（オンボの損失クイズ→08bサマリーで保有効果を作る）。
- 復元ボタン必須・価格と更新条件の明記（審査3.1.1準拠）。

### 課金ロジック

ユーザーが課金する理由は「コンテンツ」より「自分の環境を変えた実感」である。

- 止めるアプリを何個でも追加できる（2個目の追加時にPro提示）
- 通知/Live Activityのテーマを変えられる（Free=E1のみ→6テーマ解放）
- 理由別の自分の傾向・利用後リフレクション詳細分析が見える
- 週次「失った時間/取り戻した時間」レポート詳細
- 重要な時間帯の厳格モード
- テーマ・ロック画面カスタム

## 10. 北極星指標

`Conscious Saves`

定義: 対象SNSを開こうとしたが、開く前の確認または利用後リフレクションによって、次回以降の利用を自発的に減らす行動につながった回数。

補助指標:

- 1日あたり介入回数 / 開くのをやめた率 / 理由選択率
- 利用後リフレクション回答率 / 「何も得られなかった」「時間を失った」回答率
- 幸福感が増えた/変わらない/減った比率
- 通知タップ率 / Live Activity有効率 / 制限対象アプリ数
- トライアル開始率 / Pro転換率 / 解約率

## 11. ロードマップ（2026-07-24改訂: 3市場同時ローンチへ方針転換）

| --- | --- | --- |
| 実装完了済み | MVP機能 | FamilyControls配線・介入一気通貫・StoreKit2・ロック画面・計測（139テスト済み） |
| **ローンチ準備（現在）** | 3言語同時提出 | ①アプリi18n（ja/ko/en・String Catalog化）②3ストアASO ③3通貨価格（¥/₩/$）④サブスク/IAPの3言語ローカライズ ⑤3法域の法務（JP/KR 전자상거래법/US）⑥多言語CS自動化 |

**翻訳QAパイプライン（ko/en）**: Fable作成 → Codex独立レビュー → 人間ネイティブ最終確認（launch-criticalのみ）。詳細は docs/11。

**ソロ運用の必須設計**: CS/レビュー対応が3言語で発生するため、定型返信＋自動翻訳のCS自動化を最初から組む（オーナー絶対条件「CS軽い」を守るため・solo-automation連携）。

## 13. 事業化判断

やる価値あり。ただし、以下を満たすことが条件。

1. 「完全ブロック」ではなく「気づきで自発的に減らすゲート」として設計する（二層構造を崩さない）。
2. 初期市場は日本で検証し、英語圏は勝ちパターン確立後に展開する。
3. one secの遅延体験は参考に留め、意図確認と利用後リフレクションを中核機能にする。
4. MVPの成功基準を満たさない場合は、単独アプリではなくウィジェット/目標アプリにピボットする。

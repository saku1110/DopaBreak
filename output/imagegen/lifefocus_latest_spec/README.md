## 最終プロンプト仕様

### 共通

- 日本語iOSアプリ「DopaBreak」
- iPhone 16 Pro、402×874比率
- E1 Dark Mono: `#0A0B0D` / `#14171C` / `#F4F5F2` / `#7E8694` / `#C7F94D`
- 朝焼けの海写真は感情的な要所だけ。操作画面には写真を置かない
- ライムは選択・進捗・主要CTAのうち1役割に限定
- AI的な発光、SF装飾、神秘的リング、過剰なグラデーションを使わない
- 日本語を正確に表示し、iOSステータスバーとホームインジケータを含める

### 目的別分岐

- 最初の6択: 仕事で使う / 調べもの / 連絡を確認 / 投稿する / 暇つぶし / なんとなく
- 明確な目的: 呼吸を省略して5 / 10 / 15 / 30分選択へ
- 反射的な目的: 呼吸 → 今日の回数 → 全目標 → 判断
- 「自動で閉じる」は使わず「時間になったら通知でお知らせします」

### 補助状態

- 振り返りは満足度と幸福感の2段階
- 10分以上の利用途中チェックは「まだ見てる？」＋目標＋閉じるのみ
- 目標編集、対象アプリ選択、自動起動ガイドをネイティブシートとして描く

## 実装時の扱い

- 本フォルダの4枚を、旧`output/mockups/lifefocus_v2/`より新しい視覚正本として参照する。
- 各画面をSwiftUIへ実装する際は、画像内の文言より`docs/11_ui_copy.md`と現行Swiftコードを最終的な文言正本とする。
- 画像はデザイン方向・階層・余白の正本。ImageGen由来の微細な文字幅やアイコン差はそのまま写さず、SF SymbolsとDesignTokensで再現する。

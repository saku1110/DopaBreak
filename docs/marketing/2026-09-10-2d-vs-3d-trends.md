# 海外オーガニック動画：2Dとピクサー風3Dの比較

調査日：2026-09-10。対象はInstagram・TikTokで展開する短いキャラクターストーリー。写真を加工するAIフィルターや、ピクサー公式作品の人気は別の現象として扱った。

## 結論と提案

直近の投稿量・再生数・成長率を同じ条件で比較する公開資料は確認できず、「3Dの方が2Dより流行している」と市場全体について断定できない。一方、2026年のウェルネス分野には、AIを制作工程に用いた3Dキャラクター動画の大きな成功事例がある。DopaBreakでも3Dを有力候補とし、次の試作では3Dを優先して比較することを提案する。これは制作方針の判断であり、流行ランキングや獲得効率の実測結果ではない。

既存の脳キャラクターの2D素材は保持する。ユーザーによる3Dへの最終決定・新規生成指示はまだない。アプリ本体のキャラクター、広告の国・媒体、通常動画の結末に毎回宣伝を入れない方針は変更しない。

## 確認した一次資料

1. [Calm Studios公式](https://calmstudios.com/)。ブラウザの画面で、立体的な造形・毛の質感・照明を持つキャラクターを確認。ここでいう「3D」は見た目の分類で、従来の3DCG制作工程を確認した意味ではない。ピクサーによる制作という意味でもない。
2. [Google AI StudioのCalm Studios事例](https://aistudio.google.com/case-studies/calm-studios)、2026-04-14公開。ブラウザの本文で確認。Nano BananaとVeoを使ったCalmlingsの制作について紹介し、6か月未満で15億回超の動画再生、400万のSNSフォロワーを記載。運営側が提供した実績を含む導入事例であり、独立した監査や2Dとの比較試験ではない。
3. [Calmlingsのブランド向け資料](https://calmlings.com/partnerships/)。2025年8月〜2026年6月の自社公表値として、SNS合計20億回超再生、600万超のファン、広告費ゼロを記載。視聴者は25〜54歳70.1%、米国51.4%と記載。Instagram単独の数値でも、2026年9月の月間実績でもない。アプリの獲得・課金実績は示されていない。
4. [the_silent_mind0](https://www.instagram.com/the_silent_mind0/)の2D事例は同日の[個別調査](2026-09-10-the-silent-mind-reference.md)を参照。観察した3投稿は20〜30秒程度で、暗い室内・表情・短い英語字幕で生活上の感覚を描く。このアカウントとCalmlingsの数字を直接比較して画調の優劣を出すことはできない。

生成サービスのブログにも「2026年はピクサー風が流行」とする主張はあったが、比較対象・期間・集計方法が明示されていないものは判断根拠から除外した。

## 今回の企画との相性（制作仮説）

- 2D：影、姿勢、余白を使った静かな共感・内省の場面を設計しやすい。既存の参考アカウントとの距離は、主人公・色・構図で確保する。
- 3D：顔の微妙な演技やスマホの光、空間の奥行きを使う表現が候補になる。強い光沢や過剰な表情を既定にせず、大人の日常に合う落ち着いた演出を試す。
- 脳のモチーフは2Dと3Dのどちらにも使える。生々しい組織表現を避け、現在のキャラクターの識別要素を保って比較する。

## 小規模な比較案

「あと5分で就寝が遅れる」「閉じてすぐ同じSNSを開く」「目の前の会話より通知を見る」の3題材を、それぞれ2D・3Dの計6本で試す。台本、冒頭の言葉、尺、音声、誘導の位置をできるだけ揃える。まずは制作時間とキャラクターの再現性も記録する。

投稿後は媒体別に、平均視聴時間・完視聴率・視聴数あたりのプロフィール遷移を比較する。国別内訳も確認する。投稿時刻・初期配信・投稿順による差があるため、6本のオーガニック投稿を無作為化比較試験と呼ばない。1本の最大再生数だけで固定せず、複数の題材で方向が揃うかを見る。プロフィール以降の流入・課金は取得できる計測範囲で別途判断する。

今回の成果は調査と試作方針の提案。新規の画像・動画生成、投稿、広告配信は実施していない。

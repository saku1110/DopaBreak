# DopaBreak：初回検証の媒体優先順位の再評価

2026-09-11。ユーザーの「アプリの特性から最も確度が高い媒体はどれか」への調査・提案。配信・支払い・設定変更は未実施。採用確定ではない。

## 提案

少額で有料需要と購入導線を検証する確度を重視し、Apple Adsの検索結果広告 → Meta → Xの順を推奨する。実測CACで証明された順位ではなく、商品と獲得経路からの推論。9月10日のX優先提案は「X利用場面で疲れに訴える」仮説を優先したものだったが、その共感と有料獲得の確度を区別する。

- Apple Ads：スマホ制限・アプリブロック等の解決手段を探す人に接触できる。検索語ごとに設定完了・実課金を検証しやすく、動画の出来による変動を減らせる。ただし検索量、入札単価、無料・既存競合との比較が制約。Apple Ads全配信面への一般化はしない。
- Meta：就寝前や仕事中のSNS巡回を実演し、複数アプリ・夜間・集中というProの便益を説明できる。検索しない潜在層の拡大検証に有望。初回は素材・計測・購入導線の複数要因が動くため、媒体単独の判定は難しい。アプリイベント最適化は可能だが当アプリの成果を保証しない。
- X：利用場面との一致はあるが、Xだけを減らしたい人は現行の1アプリ無料で足りる可能性がある。これはMetaで単一SNSだけを訴求する場合にも共通。Xの承認MMPによる計測要件も初期準備に含める。

## 最小実験案

国を1つに固定（日本を初期案）、検索結果広告の一般キーワードを完全一致中心で検証。候補は「スマホ依存」「アプリブロック」「スクリーンタイム制限」。検索量・実際の検索意図は未確認。「集中」等の広い語、自社指名、競合指名を主力に混ぜない。予算は未確定で出稿権限もない。

新規DL → 初回介入成功 → 試用開始 → 初回実課金 → 返金を区別し、広告帰属と収益の接続を配信前に確認。試用開始を購入扱いしない。配信を14日で区切る場合も最後の獲得者の7日試用終了・購入反映まで追跡し、D35等の同じ経過日で比較する。

Apple Adsの失敗だけで商品需要なしと結論しない。配信不足・高入札なら検索媒体の制約、DL後離脱なら設定・価値提示、無料定着ならPro需要を診断し、Metaの実演訴求で再検証する。検索量が不足するか採算内で獲得できなければ、予算消化を強制せずMetaへ進む。

競合は9月5日のone sec・Opal・ScreenZen比較を参照し、今回one secとScreenZenの公式ページを再確認。呼吸・ブロックそのものは独占的な差別化ではない。目標に戻る体験を訴求仮説とするが、競合に追随困難な優位性としては未証明。

# 起動アニメーション設計仕様（Remotion / DopaBreak）

対象: アプリ起動時のスプラッシュ演出
出力: `video/launch-animation/` → MP4
キャラクター: アプリアイコンの脳キャラ

---

## 1. ストーリー（3幕・オーナー指定 2026-08-07）

**スマホに吸われている → 停止ボタンが出る → 正気に戻って回復する**

アプリの介入体験そのものを2.5秒で見せる。文字はワードマークだけ。

| 幕 | 見せるもの |
|---|---|
| 1幕 消耗 | 虚ろな目でスマホを凝視。画面をフィードが猛スピードで流れ、ライムの粒子がスマホに吸い込まれていく |
| 2幕 停止 | フィードが急停止。画面に**停止ボタン（⏸）がポップイン**。キャラが我に返って一瞬たじろぐ |
| 3幕 回復 | まばたき→ライムの閃光→**パッチリした目**。粒子が逆に立ちのぼり、暗さが晴れる。ワードマーク |

## 2. 差し替え手法（重要）

生成AIの2枚を単純にクロスフェード（Crossfade）すると線とグレインが泳ぐ。
アニメーションの定石どおり **まばたきと閃光で差し替えを隠す**。

| フレーム | ファイル | 内容 | 由来 |
|---|---|---|---|
| A0 | `frame_a0_scrolling.png` | 虚ろな目・スマホ画面はライム一色（**⏸なし**） | 既存アイコンから⏸を機械的に除去（AI再生成しないので絵が1pxもズレない） |
| B | `frame_b_blink.png` | 目を完全に閉じる・画面消灯 | gpt-image-2 |
| C | `frame_c_awake.png` | パッチリした目・ハイライト・小さな笑み・画面消灯 | gpt-image-2 |

**⏸ はPNGに焼かずRemotion側でベクター描画する。** これで出現アニメーションを完全制御できる。

## 3. タイムライン（60fps / 180フレーム = 3.00秒）

### 1幕 消耗（0–56）

| frame | 内容 |
|---|---|
| 0–40 | フレームA0。card scale 0.92、`saturate(0.82) blur(0.6px)`、重いビネット。頭部が Float（±4px・周期1.6s）。**スクロールのフィード帯**が画面内を上へ猛スピードで流れる（ループ）。ライムの粒子が上から降ってスマホに吸い込まれる |
| 40–56 | Anticipation。フィード速度1.8倍、スマホの発光が最大へ、scale 0.92→0.895・scaleY 0.97 の Squash、ビネットが締まる |

### 2幕 停止（56–92）

| frame | 内容 |
|---|---|
| 56–62 | **急停止**。フィードが6フレームで停止（強い ease-out で最後の1フレームまで減速）。画面がライム→ほぼ白に2フレームだけ跳ねる |
| 60–76 | **⏸ ポップイン**。scale 0.55 → 1.12 → 1.00（spring・1回だけ弾む）。同時にスマホからライムのリングが1回広がる（scale 0.6→2.0 / opacity 0.8→0・カード内でクリップ） |
| 68–88 | **たじろぎ**。頭部が -6px 引く＋ scale 0.895→0.915。減衰する首振り（±1.5°・8フレーム・振幅が減る）。粒子の発生停止 |

### 3幕 回復（92–180）

| frame | 内容 |
|---|---|
| 92–104 | **まばたき**。A0→B を3フレームのクロスフェード。⏸ と画面の発光は 92–100 で 0 へ（画面が消える） |
| 100–112 | **ライムバースト**。中央からライム→白のブルームが 0→1→0（ピーク **104**）。衝撃波リングはカードの外へ拡大（scale 0.2→2.6 / opacity 0.9→0）。**104でB→Cをハードカット**（クロスフェード禁止・閃光ピークで完全に隠す） |
| 104–134 | **覚醒のPop**。spring で 0.895 → 1.06 → 1.00 |
| 110–128 | **目のきらめき**。左 x=34.5% / 右 x=64%、y=40%（**白目と瞳には絶対にかけない**）。純白 `#FFFFFF`・カード幅の3.2%・最大opacity 0.9・3フレームのStagger・ライム着色とグロー禁止 |
| 108–160 | **Follow-through**。粒子が反転して上へ立ちのぼる。ビネットが緩む。`saturate` が 0.82→1.0 へ戻る。頭部後方のライムのリムグロウが1回だけ Pulse |
| 138–172 | **ワードマーク**「DopaBreak」。Fade in ＋ 12px 上へ Slide、letter-spacing 0.10em→0.02em、`Easing.bezier(0.16, 1, 0.3, 1)` |
| 172–180 | Hold。最終フレームは静止状態＝アプリUIへクロスフェードで渡せる絵 |

## 4. モーション原則（用語）

- **Anticipation**: 停止の前にフィードを加速させる。溜めがないと停止が効かない
- **Squash & stretch**: 縮み0.97 → 弾み1.06。頭部は重いので過度にしない
- **Spring / overshoot**: ⏸ のポップと覚醒のPopのみ。他は bezier
- **Follow-through**: 粒子とリムグロウは本体が止まったあとに遅れて収束する
- **Stagger**: 目のきらめきを左右でずらす（同時だと機械的）
- **Purposeful animation**: 粒子の向きが唯一の物語装置（下＝吸われる / 上＝解放）

## 5. 実装ルール（Remotion）

- CSS transition / animation / Tailwind のアニメクラスは**禁止**（レンダリングされない）
- すべて `useCurrentFrame()` + `interpolate()` / `spring()` で駆動
- `interpolate()` は必ず `extrapolateLeft: "clamp"` / `extrapolateRight: "clamp"`
- 画像は `public/` に置き `staticFile()` ＋ `<Img>`
- 粒子とフィード帯は決定論的に（`Math.random()` 禁止・indexシードの疑似乱数）
- `transform` と `opacity` 中心。`filter` は最小限

| id | 用途 | サイズ | カード |

| `LaunchSquare` | 素材確認・汎用 | 1080×1080 | 720 |

# Live Activityデザインテーマ10種 — ChatGPT一括生成プロンプト

作成日: 2026-08-17（v3: デザイン指定はChatGPTに委任。こちらからは題材・必須情報・テーマの方向性のみ渡す）
用途: ロック画面Live Activityのデザインテーマ10種のモック画像をChatGPTで一括生成する（ムード検証用）

## 経緯

- v1（色替え7種の再現）→ オーナー却下「全部同じデザインでカラー変えただけ」
- v2（テーマごとにレイアウト詳細指定）→ オーナー却下「細かいデザイン指定しないでChatGPTに任せる」
- v3: 必須情報とテーマ名だけ渡し、レイアウト・装飾・書体はChatGPTの裁量

## ChatGPTに貼るプロンプト（このままコピー）

```
あなたはモバイルUIデザイナーです。SNSを開きすぎる癖をやめたい人のためのiPhoneアプリで、ロック画面に常駐するLive Activityカードのデザインを10テーマ分デザインしてください。1テーマ1枚で画像生成し、1枚できたら確認を待たずに次へ進み、10枚すべて出し切ってください。

条件は3つだけです。

1. iPhoneのロック画面全体（縦長 1024×1536・上部にiOS時計）を描き、Live Activityカードを主役にする
2. カードに次の情報を入れる。見せ方は自由
   - ユーザーの目標「英語で商談できる自分になる」
   - 今日の実績: 開こうとした11回のうち8回開かなかった（語彙は「開かなかった」「開こうとした」を使う）
3. 10枚はテーマごとにレイアウト・装飾・書体まで別物にする。並べたとき同じアプリに見えないくらい振り切ってよい。既存キャラクターや実在ブランドの要素は使わない

テーマ10種:
1. ダークでかっこいい基準テーマ
2. 女性向けのかわいいピンク
3. 無難なノート
4. 和モダン
5. レトロ
6. ゲーム風
7. 夜空・癒し
8. ポップで元気
9. 大人の女性の手帳
10. 洗練されたミニマル

デザインはすべてあなたのセンスに任せます。1から順に生成を始めてください。
```

## 使い方メモ

- ChatGPTは1メッセージ1枚ずつ生成する。止まったら「続けて」で残りが出る
- 作り直しは「2をもっと甘く」のように番号で指示する
- モックはムード検証用。採用テーマが決まったらオーナー承認→テーマ別SwiftUI Viewとして実装（現行の5色パレット差し替え構造では表現不可のため）
- 折りたたみ状態の標準通知はiOSシステム描画のためテーマ不可。テーマが効くのはLive Activity本体と長押し展開面
- 実績コピーの実装反映（現行「今日 開かなかった 8回／開こうとした 11回」の構成見直し）は別件としてオーナー判断待ち

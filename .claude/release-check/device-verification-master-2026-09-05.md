## 3. 🟠 9/4〜9/5 の新規挙動（今週の変更・実機未確認）

### 3a. 止めるアプリの入れ替え（9/4 オーナー決定）
- [ ] 無料枠1個が埋まった状態で対象から外したアプリを開く→「Xと入れ替える」が主ボタン・**ペイウォールが出ない**・対象が入れ替わる
- [ ] 入れ替え後、外れた側のアプリを開くと「対象外です」シート→「そのまま開く」でSNSへ戻れる

### 3b. ショートカット手順の案内（9/4〜9/5）
- [ ] ホームから未検収アプリを追加→シートを閉じた直後に案内が自動で開く
- [ ] 設定から追加しても同じく開く（ホームへ戻らなくてよい）
- [ ] **検収済みのアプリを選び直しても開く**（9/5決定）
- [ ] 追加→同じシートで外す→閉じる→**開かない**
- [ ] 2個目を追加→ペイウォール→購入→ペイウォールを閉じた直後に案内が開く（9/5 Opus5指摘の是正・購入後に黙って追加される経路）
- [ ] ペイウォールで購入せず閉じる→案内は開かない・その後ホームのロック画面確認や振り返りが**止まらない**（モーダル排他の固着がないこと）
- [ ] 設定の「止めるアプリ」カードに「**ショートカットの設定方法**」の行が出て、押すと案内が開く（旧「開く前の一呼吸を設定」ではない）
- [ ] 端末を英語・韓国語にして同じ行が "How to set up the Shortcut" / "단축어 설정 방법"

### 3c. 保留中のProテーマ（9/4）
- [ ] ホームか設定でロック済みデザインをタップ→そのままペイウォールで購入→**選んだデザインになる**
- [ ] 何も選ばずに設定のPro行や週次ペイウォールから購入→黒（E1）のまま。前に触ったロック済みデザインが勝手に反映されない

### 3d. 記録画面（9/2・時間中心）
- [ ] 記録タブの主役が「取り戻した時間」で、「アプリごと」の一覧がスクリーンタイムの選択と一致する（9/2オーナー報告の食い違いが消えている）

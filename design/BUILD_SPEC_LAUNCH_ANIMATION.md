# 起動アニメーション設計仕様（Remotion / DopaBreak）

対象: アプリ起動時のスプラッシュ演出
出力: `video/launch-animation/` → MP4
キャラクター: アプリアイコンの脳キャラ

---

## 1. ストーリー（3幕・オーナー指定 2026-08-07）

**スマホに吸われている → 停止ボタンが出る → 正気に戻って回復する**

アプリの介入体験そのものを2.5秒で見せる。文字はワードマークだけ。

| 幕 | 見せるもの |
|---|---|
| 1幕 消耗 | 虚ろな目でスマホを凝視。画面をフィードが猛スピードで流れ、ライムの粒子がスマホに吸い込まれていく |
| 2幕 停止 | フィードが急停止。画面に**停止ボタン（⏸）がポップイン**。キャラが我に返って一瞬たじろぐ |
| 3幕 回復 | まばたき→ライムの閃光→**パッチリした目**。粒子が逆に立ちのぼり、暗さが晴れる。ワードマーク |

## 2. 差し替え手法（重要）

ビットマップは全フレームで `frame_a0_scrolling.png` **1枚だけ**を使い、タイル・キャラ・手・スマホの線と光沢を固定する。`Face.tsx` が1024基準のSVGでまぶた、覚醒した目、瞳、口を重ね、frame 104の白い閃光で顔の状態変更を隠す。スマホのフィード、⏸、消灯面もRemotion側のベクター描画で、frame 92–100にライム画面を光沢のある暗色面へ置き換える。ビットマップ間のクロスフェードは行わない。

### 実測座標（カード幅・高さに対する比率）

| 対象 | x | y |
|---|---|---|
| スマホ画面（角丸 r=カード幅の1.8%） | 0.3867 – 0.6016 | 0.7266 – 0.9300 |
| ⏸ 左バー | 0.4453 – 0.4863 | 0.7617 – 0.8730 |
| ⏸ 右バー | 0.5029 – 0.5439 | 0.7617 – 0.8730 |
| ⏸ グループ中心 | 0.4946 | 0.8174 |
| きらめき左（中心） | 0.296875 | 0.34375 |
| きらめき右（中心） | 0.694824 | 0.34375 |

バーの角丸 = カード幅の 0.8%、色 `#221319`。

### 本番 awake 顔（V2・2026-08-14 オーナー承認「V2でおｋ」）

`Face.tsx` は比較用variantを持たず、以下のV2形状だけを描く。座標はすべて1024基準、瞳とハイライトは `cx / cy / rx / ry` の順。

| 眼 | pupil | ハイライト1（opacity 1.0） | ハイライト2（opacity 0.96） |
|---|---|---|---|
| 左 | `399 / 505 / 60 / 92` | `379.5 / 471.819672 / 15.75 / 19.606557` | `420 / 536.672131 / 11.25 / 12.819672` |
| 右 | `619 / 503 / 59 / 91` | `599.333333 / 469.633333 / 15.884615 / 19.716667` | `640.179487 / 534.85 / 11.346154 / 12.891667` |

awake時の上まぶたは、既存のまばたきと同じ `sweepFill` / `sweepEdge` を `lidCoverage=0.13` で止めた形状とする。別レイヤーを重ねず、開瞼スイープを同じ形状上で13%へ収束させるため、二重線を作らない。V3の下まぶた弧は隈または作画ミスに見えるため不採用とし、実装へ残さない。

眉は唯一のキャラビットマップ `public/frame_a0_scrolling.png` に焼き込まれており、awake用SVGでは描き直さない。眉・口以外のビットマップ領域・スマホ・タイル背景を含め、A0を別画像へ差し替えない。

## 3. タイムライン（60fps / 180フレーム = 3.00秒）

### 1幕 消耗（0–56）

| frame | 内容 |
|---|---|
| 0–40 | フレームA0。card scale 0.92、`saturate(0.82) blur(0.6px)`、重いビネット。頭部が Float（±4px・周期1.6s）。**スクロールのフィード帯**が画面内を上へ猛スピードで流れる（ループ）。ライムの粒子が上から降ってスマホに吸い込まれる |
| 40–56 | Anticipation。フィード速度1.8倍、スマホの発光が最大へ、scale 0.92→0.895・scaleY 0.97 の Squash、ビネットが締まる |

### 2幕 停止（56–92）

| frame | 内容 |
|---|---|
| 56–62 | **急停止**。フィードが6フレームで停止（強い ease-out で最後の1フレームまで減速）。画面がライム→ほぼ白に2フレームだけ跳ねる |
| 60–76 | **⏸ ポップイン**。scale 0.55 → 1.12 → 1.00（spring・1回だけ弾む）。同時にスマホからライムのリングが1回広がる（scale 0.6→2.0 / opacity 0.8→0・カード内でクリップ） |
| 68–88 | **たじろぎ**。頭部が -6px 引く＋ scale 0.895→0.915。減衰する首振り（±1.5°・8フレーム・振幅が減る）。粒子の発生停止 |

### 3幕 回復（92–180）

| frame | 内容 |
|---|---|
| 92–105 | **まばたき**。A0の上をSVGまぶたが閉じて保持。⏸・フィード・画面発光は 92–100 で消え、同時に暗い光沢面がライム画面を覆う |
| 100–112 | **ライムバースト**。中央からライム→白のブルームが 0→1→0（ピーク **104**）。衝撃波リングはカードの外へ拡大（scale 0.2→2.6 / opacity 0.9→0）。**104で閉じたまぶたの下に覚醒顔ベクターを出す**（閃光ピークで完全に隠す） |
| 104–134 | **覚醒のPop**。spring で 0.895 → 1.06 → 1.00 |
| 110–128 | **目のきらめき**。左 x=29.6875% / 右 x=69.4824%、y=34.375%（覚醒顔の軸 x=49.58496% に対称、**白目と瞳には絶対にかけない**）。純白 `#FFFFFF`・カード幅の3.2%・最大opacity 0.9・3フレームのStagger・ライム着色とグロー禁止 |
| 108–160 | **Follow-through**。粒子が反転して上へ立ちのぼる。ビネットが緩む。`saturate` が 0.82→1.0 へ戻る。頭部後方のライムのリムグロウが1回だけ Pulse |
| 138–172 | **ワードマーク**「DopaBreak」。Fade in ＋ 12px 上へ Slide、letter-spacing 0.10em→0.02em、`Easing.bezier(0.16, 1, 0.3, 1)` |
| 172–180 | Hold。最終フレームは静止状態＝アプリUIへクロスフェードで渡せる絵 |

## 4. モーション原則（用語）

- **Anticipation**: 停止の前にフィードを加速させる。溜めがないと停止が効かない
- **Squash & stretch**: 縮み0.97 → 弾み1.06。頭部は重いので過度にしない
- **Spring / overshoot**: ⏸ のポップと覚醒のPopのみ。他は bezier
- **Follow-through**: 粒子とリムグロウは本体が止まったあとに遅れて収束する
- **Stagger**: 目のきらめきを左右でずらす（同時だと機械的）
- **Purposeful animation**: 粒子の向きが唯一の物語装置（下＝吸われる / 上＝解放）

## 5. 実装ルール（Remotion）

- CSS transition / animation / Tailwind のアニメクラスは**禁止**（レンダリングされない）
- すべて `useCurrentFrame()` + `interpolate()` / `spring()` で駆動
- `interpolate()` は必ず `extrapolateLeft: "clamp"` / `extrapolateRight: "clamp"`
- 画像は `public/` に置き `staticFile()` ＋ `<Img>`
- 粒子とフィード帯は決定論的に（`Math.random()` 禁止・indexシードの疑似乱数）
- `transform` と `opacity` 中心。`filter` は最小限

## 6. コンポジション

| id | 用途 | サイズ | カード |
|---|---|---|---|
| `LaunchSquare` | 素材確認・汎用 | 1080×1080 | 720 |
| `LaunchPortrait` | iPhoneスプラッシュ | 1290×2796 | 460（中心を高さ46%） |

カードの角丸 = カード幅 × 0.2237（iOSのスーパー楕円に近い値）。両コンポは同じコンポーネントを描画しタイミングを共有する。

## 7. 出力

```
npx remotion render LaunchSquare   out/launch-square.mp4
npx remotion render LaunchPortrait out/launch-portrait.mp4
```

V2本採用レンダーは比較用 `-v2` を残し、`out/launch-square-v3.mp4` と `out/launch-portrait-v3.mp4` へ出力する。検証静止画は `out/fix3/f30.png`、`f100.png`、`f104.png`、`f105.png`、`f112.png`、`f117.png`、`f150.png`、`f179.png` を正本とする。

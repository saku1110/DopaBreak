# 1日に開ける回数（回数上限で完全ブロック）設計

- 日付: 2026-10-05
- オーナー決定: 「Aを有料機能に入れて」。A＝上限に届いたら翌朝まで止まる。緊急用に30秒待てばその場で1回だけ開ける（使い終わればまた止まる）。上限の数を緩める変更は翌日から
- 前提として提示し異論がなかった案: 一呼吸の画面に「今日あと◯回」を出す／上限は本人の記録から提案する／止まった画面には理由と終わる時刻だけ／SNS合計で数える／区切りは起床時刻／Pro
- 経緯: 8/22に常時シールドの一部として作った回数上限は、9/1の一呼吸と完全ブロックの分離で常時シールドごと外れた。今回はふだんは一呼吸だけで、使い切ったときだけ完全ブロックがかかる

## 1. 振る舞い

| 項目 | 決め |
|---|---|
| 数えるもの | 一呼吸のあと「開く」を選んだ回（時間あり・時間なし・確認通知つきのすべて）。素通し（決めた時間内の開き直し）は数えない。キャンセルは数えない |
| 数える範囲 | 一呼吸の対象アプリの合計（アプリ別は持たない） |
| 1日の区切り | 起床時刻（未設定は7:00）。区切りから次の区切りまでを「今日」とする |
| 止める対象 | 完全ブロックに登録したアプリ（ルールの選択データ）。一呼吸だけに登録したアプリは、一呼吸の入口で上限画面を出して止める（Screen Timeでは止めない） |
| 止まり始め | 上限に届いた回の「決めた時間」が終わった時刻。最後の1回は時間なしを選べない |
| 止まり終わり | 次の起床時刻 |
| 緊急用 | 30秒待つ（待ち始めた時刻を保存し、画面を閉じても短縮できない）→ 時間を選ぶ → その時間だけ完全ブロックを外し、一呼吸の対象アプリを素通しにする → 時間が過ぎたらまた止める。回数の制限はない（9/5の「回数制限付き緊急パス」不採用と揃える） |
| 設定の変更 | オンにする・減らす＝すぐ効く。増やす・オフ＝次の起床時刻から効く。オンにした日は、オンにした時刻以降の回だけを数える |
| 権利 | Pro。Freeへ落ちたら監視と控えとシールドを外し、設定値は残す（夜だけ強化と同じ非破壊降格） |
| 権利が未確定 | 何も触らない（`ShieldSyncPolicy.preserve` と同じ） |

## 2. 画面

- 設定「ブロック」カード: 手動・毎週・就寝のトグルの下に「1日に開ける回数」（オフ／3／5／8／10／12／15／20／30回）。下に「最近7日は1日平均◯回」と、変更待ちがあれば「明日の7:00から◯回」。Freeはカードごと既存のペイウォール導線
- 一呼吸（呼吸中）: 目標カードの下に「今日あと◯回」
- 時間選択: 最後の1回のときだけ「今日はこれが最後の1回です」「この時間が過ぎると明日 7:00 まで開けません」。時間なしのトグルを出さない
- 上限画面（使い切ったあとに一呼吸が呼ばれたとき）: 「今日は12回開きました」「明日 7:00 まで開けません」、ボタン「閉じる」「30秒待って開く」
- 緊急の待ち: 残り秒数。0秒で時間選択へ
- ホーム: 回数上限で止まっているあいだ、対象アプリのカードに状態行と「30秒待って開く」
- シールド: 回数上限だけが効いているとき 題「今日は12回開きました」副「明日 7:00 まで開けません」＋「急ぐときはDopaBreakから開けます」。iOS 26.5以降は副ボタン「DopaBreakを開く」。夜・予定・手動と重なるときは従来の「完全ブロック中」に1行足す

## 3. 実装

| 層 | 追加・変更 |
|---|---|
| Core | `DailyOpenLimitSettings`（現在値・変更待ち・数え始め・緊急の待ち開始）、`DailyOpenLimitPolicy`（区切り・残り・変更の効き方・窓の判定の純関数）、`DailyOpenLimitShieldSnapshot`（拡張用の控え）、`SnapshotFile.dailyOpenLimitShieldSnapshot`、`SQLiteLogStore.openedAttemptCount(from:to:)`、`InterventionEngine.recordLimitOverrideOpen`、`EntitlementGate.dailyOpenLimitAllowed`、`SettingsStore.dailyOpenLimitSettings` |
| アプリ | `DailyOpenLimitController`（控えの書き込み・DeviceActivity `dopabreak.openlimit` の登録と停止・ManagedSettings `dopabreak.openlimit` の適用と解除・前面復帰の同期・緊急・降格と全削除の後始末）。`AppModel` に状態と操作を足し、`syncShield()` の中で同期する |
| 介入フロー | `InterventionFlowStage.limitReached` と `.emergencyWaiting` を追加。開いた直後に残り0なら止まり始めを登録 |
| 拡張 | Monitor: 活動名 `dopabreak.openlimit` の開始で控えが窓の内なら適用・終了で窓の外なら解除。ShieldConfig: 控えの対象かつ窓の内なら回数上限の表示。ShieldAction: 回数上限だけのときに26.5以降で親アプリを開く。`ReinterventionShield.hasHardBlock` に回数上限を含める（再介入の表示より優先） |
| 抑止 | `suppressesIntervention` には含めない（上限画面を出すため） |

DeviceActivityの窓は15分以上必要。止まり始めから起床まで15分未満なら監視を張らず、シールドも掛けない（一呼吸の入口の上限画面だけで止める。解除の担い手がいないシールドは掛けない）。

### Codex Astra medium との設計議論で取り入れた点（2026-10-05）

- 控えの読み書きとシールドへの反映を、プロセスをまたぐファイルロックの中で行う（`DailyOpenLimitStore`）
- Monitorは開始・終了の区別に頼らず、どの通知でも最新の控えで掛け外しを決め直す
- 解除を出す監視の登録に成功したときだけ控えを残す。失敗したら控えを消して掛けない
- 緊急は止め直しの監視を先に登録してから外す。登録できなければ外さない（元の窓を張り直す）
- 夜・予定・手動が重なるときは緊急の導線を出さない（外せるのは回数上限ぶんだけ）
- 「開く」確定の直前にも残り回数を確かめ直す。「明日」は終わる時刻が翌日のときだけ付ける
- 緊急の待ちは30秒後から5分以内だけ有効。使ったら消費し、使い回せない
- 権利が未確定でも、終わった窓のシールドは外す

取り入れなかった点: 残数確認と記録の同一トランザクション化（一呼吸は同時に1つしか進まないため）、再Pro時に数え始めを有効化時刻へずらす（同じ日に降格→再購入した場合だけの差で、使い切っていればその場で止まる）。

### Codexコードレビュー（Astra medium）で直した点（2026-10-05）

- 同期のたびに解除の監視が登録されているかを確かめ、無ければ張り直す（控えを書いてから登録するまでに終了した場合の保険）。張れなければ外す
- 止まっているあいだに起床時刻を変えたら、止まり終わりを今の起床時刻へ合わせ直す
- 止まっているあいだに完全にブロックするアプリを足したらすぐ止める。外したアプリは翌朝まで止めたまま（緩める変更は翌朝から）
- 緊急で開くときは、同じアプリの利用時間の通知・制限（再介入）の区切りも終える（そちらのシールドで開けないままになるため）。終了は素通しの許可を取り消すので、許可より先に行う
- 上限画面を開いたまま朝を迎えた・Freeへ戻ったときは、緊急ボタンを押した時点で状態を取り直し、一呼吸からやり直す
- 最後の1回の決めた時間・緊急で開いた時間のあいだは、ホームと設定で「{時刻} まで開けます」と出し、緊急ボタンを出さない
- 深夜に変えて同じ日の朝に効く変更待ちは「明日」を付けない

## 5. 検証

Coreの純関数とストアの単体テスト。アプリのフロー（上限画面・最後の1回・緊急の待ち）とコントローラ（偽の監視とストアで、登録・適用・解除・降格）のテスト。全ターゲットのビルド。シミュレータで設定・一呼吸・上限画面・ホームを撮影。Screen Timeのシールドが実際に掛かる・外れるのは実機でのみ確認できる。

### Codex再レビュー（2回目）で直した点（2026-10-05）

- 監視が登録されているかを、名前の有無ではなく `DeviceActivityCenter.schedule(for:)` の開始・終了の時刻で照合する（起床時刻を変えた直後に終了して古い終わりの予定が残った場合も張り直せる）
- 「{時刻} まで開けます」は、最後の1回・緊急で開いたときに覚えた終わりの時刻（`DailyOpenLimitSettings.openUntil`）だけで出す。止まっている最中は必ず出さない（利用時間の通知・制限をつないだアプリは素通しの許可が最大12時間になるため、許可の期限は使わない）
- 上限画面・緊急の待ちを出しているあいだは、前面へ戻ったときと1分ごとに状態を確かめ直す。緊急の時間を確定する直前にも確かめ、上限がもう効いていなければ一呼吸からやり直す
- （3回目）控えを作り直すときの止まり始めに、素通しの許可の期限を使わない。最後の1回で覚えた終わりの時刻を使い、無ければいまから止める

## 共通生成条件

- 日本語iOSアプリ「DopaBreak」、iPhone 16 Proの402×874比率、フルブリードの単体画面。
- iOSステータスバーとホームインジケータを含み、端末フレーム、手、プレゼンボード、透かしは含めない。
- E1 Dark Mono: 背景`#0A0B0D`、カード`#14171C`、主文字`#F4F5F2`、補助`#7E8694`、ライム`#C7F94D`。
- AI的な発光、SF装飾、過剰グラデーションを使わない。操作画面には写真を使わない。
- 参照画像はスタイル・階層・余白の参照のみで、編集対象として扱わない。

## 最終プロンプト仕様

### 1. Home初日ゼロ状態

- 参照: `output/imagegen/lifefocus_latest_spec/01_anchor_screens.png`
- 朝焼け海を暗色オーバーレイ付き約132pt帯にし、`TODAY · JUL 12`を置く。`0回/今週`は非表示。
- 目標カードは`あなたの目標` / `SNSの先ではなく、戻りたい先を決める`。
- ヒーローは`最初のひと呼吸から\n今日が始まる`、補助は`対象アプリを開こうとすると、ここに記録がつきます`。
- 巨大な0、0回メトリクス、週カード、達成色のライムを置かない。タブは`ホーム / 目標 / 統計 / 設定`でホームだけ選択。
- 初回生成後、写真帯の高さだけを縮め、他要素を固定する単一変更の編集を実施。

### 2. Paywall固定CTA＋2段プラン

- 参照: `output/imagegen/lifefocus_latest_spec/01_anchor_screens.png`
- `DOPABREAK PRO`、細い朝焼け帯、`その38日を、人生に使う`（38のみライム）、説明文を上部に配置。
- 機能4行は`止めるアプリを何個でも追加できる / ロック画面テーマを着せ替え / 詳細な統計と継続記録 / 複数の目標とモード`。
- 年額`4,980円/年`を選択し、`一番人気・58%お得`、`月あたり415円・7日間無料`を表示。月額は`980円/月`。買い切りと旧価格は不使用。
- 法務表示と`利用規約 / プライバシー`の直下に、固定`7日間無料で始める`、`購入を復元 / あとで`を置く。

### 3. 直行ルート時間選択

- 参照: `output/imagegen/lifefocus_latest_spec/02_direct_purpose_route.png`
- `TIME`、`何分だけ\n開きますか？`、仕事カード、`目的が明確なため、一呼吸を省きました`を表示。
- `5分 / 10分 / 15分 / 30分`の2×2。10分だけライム選択。
- `時間になったら通知でお知らせします`、主CTA`10分だけ開く`の直下に、枠なし・背景なし・補助色の`開かずに戻る`を置く。

### 4. オンボ目標入力の軽量化

- 参照: `output/imagegen/lifefocus_latest_spec/01_anchor_screens.png`
- `06 / 14`と進捗、`あなたの目標 / GOAL`、`空いたこの時間で\n何をしますか？`を表示。
- 入力は1つだけで`例: 英語で話せるようになる`。例文チップは`読書を30分 / 筋トレを続ける / 資格の勉強`。
- `ロック画面に出す短い言葉(任意)`を折りたたみ行にし、カテゴリ、期限、チェックリスト、架空の入力済み目標を置かない。
- 下部は`次へ`と、正本文言`あとで設定する`。

## 実装時の扱い

- 画像は情報階層・余白・強弱の正本。文字列は`docs/11_ui_copy.md`と現行SwiftUIを最終正本とする。
- ImageGen由来のアイコンを切り出さず、実装はSF Symbolsと`DesignTokens.swift`で再現する。
- Dynamic Typeでは固定画面をそのまま縮小せず、スクロールまたは再フローでCTAと副アクションの到達性を維持する。

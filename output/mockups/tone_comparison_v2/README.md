## E1 Dark Mono（現行）
- 冷たい規律。Oura / Linear / Whoop 系。アクセント electric lime `#C7F94D`。
- 強み: 「計測・制御」の説得力。数字が主役のStats/介入と好相性。28画面すべて完成済み＝追加コストゼロ。
- 弱み: 海外ブロッカー競合（Opal/one sec/Jomo）と同じ「テック計測器」の世界観に見えやすい。「責めずに気づかせる」情緒は薄い。

## F1 墨と灯（新提案）
- 和のエディトリアル。墨色の温かい闇 `#0F0D0A` × 灯りの琥珀 `#E4A14E` × 明朝体（Shippori Mincho B1）の見出し。
- 設計意図: 本アプリのモートは「夜、SNSの後の正直な気持ちを記録する」内省の瞬間。計測器ではなく**夜の日記/床の間の静けさ**として組むことで、(1)「禁止しない・責めない」ポジショニングと感情が一致 (2)全競合が寒色テックである中で唯一の温かい和トーン＝スクショ1枚で識別可能 (3)「人生に、戻る」（推奨名Modoru）のブランド世界観と直結。
- 弱み: 28画面の再スキニングコスト（HTML変数差し替えが主で機械的だが1セッション相当）。数字密度の高いStatsでの説得力はE1に劣る可能性。

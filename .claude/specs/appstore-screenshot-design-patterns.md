# App Store スクリーンショット デザインパターン 10案 仕様書

作成日: 2026-08-16
対象: DopaBreak / iPhone 6.9インチ（1320 × 2868）
スコープ: **背景デザイン＋デバイスモックまで**。アプリ画面（スクリーン内）は後日オーナーが実撮影して差し込む。

---

## 0. この仕様の目的

10通りの「枠デザイン」を同一コピー・同一プレースホルダで並べ、デザイン差だけを比較できる状態にする。
コピー・撮影画面は変数として固定するため、比較で見えるのは構図・背景・モックの質のみになる。

出力:

| 成果物 | パス |
|---|---|
| パターン10枚 | `output/app-store-screenshots/design-patterns/P01..P10-<slug>.png` |
| 比較コンタクトシート | `output/app-store-screenshots/design-patterns/contact-sheet.png` |
| スクリーン差し込み座標 | `output/app-store-screenshots/design-patterns/slots.json` |
| 生成スクリプト | `scripts/generate-screenshot-design-patterns.py` |

## 2. 固定コピー（全パターン共通・比較のため変えない）

日本語ディスプレイコピー規則に準拠（リズム目的の読点なし・句点なし・体言止め基調）。

```
eyebrow  : SNS時間を見える化
headline : 「あと5分だけ」が / 1年で35日になる     ← 2行
sub      : 回答から無意識スクロールの時間を推計
```

P10のみ数字ヒーロー用に追加:

```
number   : 35
unit     : 日
```

## 3. デバイスモック（共通仕様）

10パターンのうちモックを使うものは、同一の描画関数 `draw_device()` を使う。

```
入力: 外形幅 W_out, 回転角 deg, 影の有無
```

| 要素 | 値 |
|---|---|
| 画面アスペクト | **厳密に 1320 : 2868**（実撮影を無変形で差し込むため） |
| ベゼル厚 | `round(W_out * 0.0275)`（四辺均等） |
| 外形角丸 | `round(W_out * 0.148)` |
| 画面角丸 | `外形角丸 - ベゼル厚` |
| 筐体色 | チタン風の縦グラデ `#3A3F45` → `#1B1E22`、外周に 1px の `#5A6169` ハイライトリング |
| ベゼル内側 | `#000000` |
| Dynamic Island | 画面幅の 30%、高さ 3.1%、上端から 2.1%、中央、塗り `#000000`、角丸は高さの半分 |
| 影 | 画面幅 12% のガウスぼかし、`(0,0,0,150)`、下方向に外形高さの 3% オフセット |

**プレースホルダ描画**（実撮影が入る領域を明示する）:

- 塗り: `#14171B`
- 40px グリッド線: `#22262C`
- 中央に2行: `SCREEN` / `1320 × 2868` — SFNS bold、`#5B626C`
- 対角線を薄く2本引く（`#1E2228`）

回転がある場合は、モック全体を RGBA で別レイヤーに描いてから `Image.rotate(deg, resample=BICUBIC, expand=True)` し、合成する。
`slots.json` には**回転前**のローカル座標と、キャンバス上のアンカー・回転角の両方を書く。

## 4. パターン定義

すべて 1320 × 2868。`M = 99`（= 幅の7.5%）を基準マージンとする。

### P01 — anchor-bottom（王道・現行の改良版）

- 背景: 縦グラデ `#12151A` → `#0B0D0F`。上端から高さ30%の位置に中心を置いたライムのラジアルグロー（`accent` 透明度28、半径 = 幅の85%、ぼかし 幅の18%）
- ヘッダー: 左上にアプリアイコン（幅の8.6%・角丸22%）＋ `DopaBreak`（bold, 幅の3.1%, `primary_text`）。カウンタ表記は**入れない**（現行の `01 / 07` は廃止）
- eyebrow: 中央ピル。塗り `#232B18`、文字 `accent`、上下パディング = 高さの0.85%、左右 = 幅の2.4%
- headline: 中央揃え2行、bold、幅の6.6%、行間 = 高さの0.75%
- sub: 中央揃え1行、regular、幅の2.9%、`secondary_text`
- デバイス: 外形幅 = 幅の76%、中央 X、上端 Y = 高さの33.5%。**下端はキャンバス外へブリード**
- 回転なし

### P02 — full-bleed（ノーフレーム全面）

- デバイスフレームなし。スクリーンスロットが**キャンバス全面** (0,0,1320,2868)、角丸0
- 上部スクリム: 高さ0〜42%に黒の縦グラデ（不透明度 235 → 0）
- 下部スクリム: 高さ88%〜100%に黒 0 → 180
- テキストは上部スクリム上に配置（eyebrow → headline → sub、中央揃え、上端 Y = 高さの9%）
- ヘッダーのアイコン・ブランド名は**下部**に小さく置く（中央、アイコン幅の6%＋`DopaBreak`）
- 狙い: 一覧で最も画面の中身が伝わる。テキスト可読性はスクリム依存なので、実撮影が明るい画面のときは要検証

### P03 — tilt（斜め・奥行き）

- 背景: `#0B0D0F` ベタ＋左上から右下へ走るライムのライトシャフト（幅 = 幅の55%、角度 -28°、`accent` 不透明度18、ぼかし 幅の12%）
- テキスト: **左寄せ**。左端 = M。eyebrow ピルも左寄せ
- デバイス: 外形幅 = 幅の70%、**回転 -8°**、中心 X = 幅の58%、上端 Y = 高さの36%、下端ブリード
- 影を強め（オフセット 高さの2.5%、ぼかし 幅の14%）
- 狙い: 静的な直立モックが並ぶ一覧の中で動きが出る

### P04 — lime-hero（アクセント全面・視線ストッパー）

- 背景: ライム縦グラデ `#C7F94D` → `#9FD52F` 全面
- テキストは `ink` (`#0A0C0E`)。eyebrow ピルは塗り `#0E1011` / 文字 `accent`
- ヘッダーのブランド名も `ink`
- デバイス: P01と同一ジオメトリ（外形幅76%、Y=33.5%、下端ブリード）
- 狙い: セット内で1枚だけ使う視線ストッパー。連続使用は禁止

### P05 — split-block（上下2分割・エディトリアル）

- 上ブロック: Y=0〜高さの38%、塗り `accent`。境界は水平直線
- 下ブロック: 残り、`#0B0D0F`
- テキストは上ブロック内、**左寄せ**、`ink`。eyebrow は下線付きラベル（ピルではなく `ink` の2px下線）
- ヘッダーアイコン＋ブランド名は上ブロック左上
- デバイス: 外形幅 = 幅の68%、中央 X、上端 Y = 高さの30%（**境界をまたいで下ブロックへ入る**）、下端ブリード
- 狙い: 情報が整理されて見える。境界の直線がサムネでも効く

### P06 — character-duo（マスコット併置）

- 背景: `#0B0D0F` ＋ 左下寄りに `amber_glow` のハロー（不透明度70、半径 = 幅の55%、ぼかし 幅の20%）
- キャラ `doom.png` を左に配置: 高さ = 高さの30%、左端 = 幅の -4%（一部を画面外へ出す）、下端 Y = 高さの93%
- デバイス: 外形幅 = 幅の58%、中心 X = 幅の68%、上端 Y = 高さの40%、下端ブリード。キャラと**わずかに重ねる**（キャラが手前）
- テキスト: 上部中央、eyebrow ピル → headline → sub
- 狙い: アプリアイコンのキャラと一貫。ブランド想起が最も強い

### P07 — diagonal-sweep（対角の色面）

- 背景: `#0B0D0F`。左上 (0, 高さの18%) → 右上 (1320, 0) → 右下 (1320, 高さの62%) → 左下 (0, 高さの80%) の四角形を `accent` で塗る（＝画面を横切る斜めのライム帯）
- テキストは**帯の上（黒地）** に置く: eyebrow → headline → sub、中央揃え、上端 Y = 高さの7%。文字は `primary_text`
- デバイス: 外形幅 = 幅の72%、中央 X、上端 Y = 高さの40%（**ライム帯と黒地の境界をまたぐ**）、下端ブリード
- 狙い: 帯がサムネでも識別できる。デバイスが境界に刺さって奥行きが出る

### P08 — light-break（明転）

- 背景: 縦グラデ `#EDEFE9` → `#DCDFD6`
- テキストは `ink`。sub は `#5B626C`。eyebrow ピルは塗り `#0A0C0E` / 文字 `accent`
- ヘッダーのブランド名は `ink`
- デバイス: 外形幅 = 幅の72%、中央 X、上端 Y = 高さの35%、下端ブリード。**影を柔らかく大きく**（ぼかし 幅の16%、不透明度 90）
- 狙い: ダークUIのアプリ一覧の中で明度が反転し、スクロール中に必ず目に入る

### P09 — stacked-pair（2台重ね）

- 背景: `#0B0D0F` ＋ 中央下のライムグロー（不透明度22、半径 = 幅の70%、ぼかし 幅の16%）
- 奥のデバイス: 外形幅 = 幅の52%、回転 +9°、中心 X = 幅の33%、上端 Y = 高さの40%。**暗く**（合成後に不透明度0.62の黒を乗算相当で被せる）
- 手前のデバイス: 外形幅 = 幅の62%、回転 -3°、中心 X = 幅の62%、上端 Y = 高さの44%、下端ブリード
- スクリーンスロットは**2つ**（`back` / `front`）
- テキスト: 上部中央
- 狙い: Before/After や2機能を1枚で見せる

### P10 — big-number（タイポ主役）

- 背景: `#0B0D0F`
- 地紋: `35` を SFNS bold・字高 = 高さの42% で中央上寄せに描き、`accent` 不透明度 34 で敷く（**テキストの背後**）
- eyebrow → headline → sub は数字の上に重ねて中央揃え、上端 Y = 高さの11%
- デバイス: 外形幅 = 幅の56%、中央 X、上端 Y = 高さの47%、下端ブリード
- 狙い: 数値訴求パネル専用。数字がサムネで最初に読める

## 6. slots.json 形式

実撮影を後から差し込むための座標表。

```json
{
  "canvas": {"width": 1320, "height": 2868},
  "screen_aspect": "1320:2868",
  "patterns": [
    {
      "id": "P01",
      "slug": "anchor-bottom",
      "file": "P01-anchor-bottom.png",
      "slots": [
        {
          "name": "main",
          "x": 0, "y": 0, "width": 0, "height": 0,
          "corner_radius": 0,
          "rotation_deg": 0,
          "rotation_center": [0, 0],
          "note": "回転がある場合、x/y/width/height は回転前のローカル座標。rotation_center を中心に rotation_deg 回転させてから差し込む"
        }
      ]
    }
  ]
}
```

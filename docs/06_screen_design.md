# 画面設計書

作成日: 2026-06-27 / 最新改訂: 2026-07-12（朝焼けアクセント、目的確認先行、目的別介入、実測値のみのHomeを反映）

## 1. デザイン方針

UIは、罪悪感ではなく「戻る場所」を感じさせる。スクリーンタイム管理の冷たい印象を避けつつ、神秘的な装飾には寄せない。黒背景、数字、バー、短いラベルで集中と制御を表現する。

目標管理やアファメーションではなく、SNS依存改善とDeep Focusを主軸にする。利用後リフレクション画面は、ユーザーを責める画面ではなく、SNS後の満足感を静かに観察する画面として設計する。

原則:

- 介入画面は短く、迷わせない。
- 目標表示は大きく、行動ボタンは少なく。
- 叱らない。問いかける。
- 目標は種類ラベルのないフラットリスト。Freeは1件、Proは複数件。タスク管理画面にしない。
- 円形リングや魔法陣のように見える装飾は使わない。
- ビジュアルトークンは **E1 Dark Mono で確定**（2026-07-02 オーナー決定。背景 `#0A0B0D` / カード `#14171C` / 主 `#F4F5F2` / 副 `#7E8694` / アクセント electric lime `#C7F94D` を各画面1役割に限定）。F1墨と灯はProテーマ第1弾候補。
- 朝焼けの海写真は「人生に戻る」感情を担う **Welcome / Home / Ready / Paywall / Notification preview** にだけ使う。介入・設定・入力画面は無写真のE1 Dark Monoを維持する。
- 写真には固定の暗色オーバーレイを重ね、写真の明部でも主テキストのコントラストを維持する。

## 5. 目的確認先行の介入フロー（2026-07-12 正本）

通常介入は対象アプリを開く目的の確認から始める。

```text
何のために開きますか？
├─ 仕事 / 調べもの / 連絡 / 投稿
│  └─ 呼吸・回数・目標確認を省略 → 対象SNSを開く
└─ 暇つぶし / なんとなく
   └─ 一呼吸 → 今日の回数と全目標を確認し、その画面で判断
      ├─ 開かない → 「開かなかった。あなたの勝ち」
      └─ 開く → 対象SNSを開く
```

- standardでは他社SNSのリアルタイム使用時間を取得できないため、時間選択・時間切れ通知・中間チェックインを表示しない。
- シールド一時解除では実際の解除期限が必要なため、5/10/15/30分の時間選択だけを残す。通知は予約しない。
- 正式な画面文言は [docs/11_ui_copy.md](./11_ui_copy.md)、状態遷移は [docs/12_hybrid_intervention.md](./12_hybrid_intervention.md) を優先する。

### Screen S-07 Post-Use Reflection

SNSを使った後の振り返り画面。通常のSNS起動では終了時刻を検知できないため自動表示しない。シールド一時解除では以下で表示できる。

- 再シールド時
- アプリ復帰時

目的:

- SNSを責めず、見た後の実感を記録する。
- 「楽しかった」「何も得られなかった」などを自分で観察させる。
- 次回以降、自発的に開く回数を減らしたくなる状態を作る。

表示:

```text
SNSを見てどうだった？

[満足感があった]
[楽しかった]
[何も得られなかった]
[時間を失った感じがする]
[気分が下がった]

[今回はスキップ]
```

満足度の選択時に1タップで記録して閉じる。幸福感変化は満足度から導出して保存し、統計表示は維持する。

回答後:

```text
記録しました。

次に開く前の判断に使います。

[閉じる]
[次から強める]
```

UI:

- 黒背景ベース。選択肢は大きなカード型。
- ネガティブ回答を赤くしすぎない。罪悪感ではなく観察として扱う。
- `次から強める` はDeep Focusや夜だけ強める設定へ誘導する。

**注記: 本画面は差別化の中核。モックは 23_post_reflection.html（E1）と tone_comparison_v2/F1_reflection.html（新提案）の2トーンで作成済み（2026-07-02）。**

## 6. Home

目的: 今日の状態と「自分で選べた」という達成感を1画面で見せる。

構成:

```text
TODAY ・ 7月12日             14回 / 今週
[朝焼けの海・高さ約132pt]

あなたの目標
英語で仕事ができる自分になる

14回
今日 自分で選べた
開こうとした18回のうち、78%で立ち止まれました

14回 開かずに戻れた | 18回 開こうとした

THIS WEEK
今週14回、自分で選び直しました
```

設計:

- 朝焼けは上部の短い帯に限定し、目標と達成指標をファーストビュー内に残す。
- Homeの主指標はAttemptLogから正確に算出できる「自分で選べた回数」。
- 「SNSを使わなかった時間」はDeviceActivity等の実測値を取得できるまで表示しない。回数×固定分や選択時間から推測しない。
- データ0件では「最初の選択から、今日の記録が始まります」と表示する。
- ロック画面の表示カード（アプリ内でライブアクティビティをオンにしているときだけ）: 端末で許可されていればテーマのプレビュー。端末の設定で許可されていなければ、プレビューの代わりに「ロック画面の表示がオフ」＋説明＋「設定を開く」を出す（2026-09-26 オーナー承認）。iOSの最初の確認で「許可しない」を選んだ人が、目標が出ていないことに気づけるようにするため。設定から戻ると前面復帰の再取得でプレビューに戻る。文言はロック画面確認と共通（[UI文言集](11_ui_copy.md) §20）。

## 9. ロック画面サーフェス（2026-07-02 オーナー決定: 常設ウィジェット廃止）

**旧・ロック画面常設ウィジェット（WidgetKit accessory系）は廃止。** 理由: 設置に手動セットアップが必要でActivationのボトルネック（旧KPI設置率40%）だった。戻る先の表示はLive Activityに一本化する。

### 9a. Lock Notification（週次レポート通知）

構成（`output/mockups/lifefocus_v2/20b` / テーマ版 `output/mockups/notification_themes/`）:

```text
[アイコン] DopaBreak                now
● 取り戻した時間 · 今週   6時間20分
  開かずに我慢 142回 · 12日連続
```

- 週次レポート通知は設定時刻ちょうど・月曜に送る。
- **iOS制約**: 折りたたみ状態の標準通知はカード色・レイアウト変更不可（システム描画）。テーマが効くのは長押し展開時のカスタムUI（Notification Content Extension）と添付サムネイルのみ。

### 9b. Daily Live Activity（常設ウィジェットの実質代替・テーマの主戦場）

- ActivityKitでロック画面下部に**カスタムUIカードを常駐**（通知と同じ構成＋「今日止まれた回数」がライブ更新）。
- **テーマ6種が全面適用できる唯一のロック画面面**（E1 Dark Mono=Free / 墨と灯・朝霧・森林・夜更け・K-POPパステル・かわいいピンク=Pro）。
- 制約: 1アクティビティ最大8時間 → 朝の起動/介入時に開始・更新で延長。ユーザーが手動で消せる。
- 審査注記: Live Activityは「進行中のアクティビティ」要件があるため、「今日のゲート実績（止まれた回数・取り戻した時間がライブ更新される）」として設計する（静的な目標表示のみにしない）。
- Dynamic Island対応（コンパクト: 止まれた回数）。

短縮表示名（12-16文字）はホームウィジェット・介入画面・Dynamic Islandで引き続き使用する。

表示:

```text

         開く前にブレーキ            ← 中央揃え・1行固定

└──────────────────────────────────┘
┌ 月額 ────────────────────────────┐
│  980円/月                                            │
└──────────────────────────────────┘
```

表示ルール（2026-07-21確定）:

- **見出しブロックは中央揃え**（2026-09-04確定・文言正本は docs/11 §5「2026-09-04 ペイウォール見出しの人生年数化＋中央揃え」）。中央化するのは見出し2行・推計注記・サブコピーだけで、Proでできること・プランカード・法務・下部CTAは左揃えのまま。**キャラクターカード上の `DOPABREAK PRO` ラベルは `.topLeading` のまま**（中央上へ寄せるとキャラクターの頭に重なる・2026-09-04 実画面で確認）。見出しは1行目・2行目とも `dopaDisplayClamp()` による1行固定（縮小下限0.5・Dynamic Typeはaccessibility2で打ち止め）
- **{Y}（人生年数）と{T}（1日の利用時間）はSelfCheck回答からの推計**。固定値のハードコード禁止。50年という前提は推計注記に必ず出す（景表法・docs/07 O-03r と同方針）
- **2プラン表示**（年額＋月額）。買い切りはペイウォールから外し、Settings「アカウント/課金」の買い切り行で提示（→ §11）。根拠: 2プランが業界標準41-60%・3+は選択麻痺（docs/15 §3.3）
- **請求額をいちばん大きく（2026-09-26 オーナー承認・審査3.1.2対応）**: 年額カードの大きい数字は「4,980円/年」、月額カードは「980円/月」。年額の月あたり（StoreKit実価格÷12）は「月あたり415円」として請求額の下に小さく出す。月あたりを請求額より大きく・上に出す旧「月換算ヒーロー表示」は1.0.2の却下理由のため使わない
- 法務文言にも請求額を明記する（従来どおり）。景表法有利誤認の回避と返金率抑制（Productivityは返金率最高4.7%）の方針も維持
- 月換算表示の実証: 年額の「$X/月」表記でトライアル開始+30%・年額比率+10%（SOSA 2026 LatAm実測・trial→有料は不変）

## 13. 文言トーン

悪い例:

- またSNSを開こうとしました
- 意志が弱いです
- 依存しています

良い例:

- いま、本当に必要ですか？
- 戻る先を思い出しましょう
- 必要な時間だけ使いましょう
- 開かない選択を記録しました
- SNSを見てどうでしたか？
- 次に開く前の判断に使います

避ける表現:

- また無駄にしました
- だからSNSは悪い
- 幸福感が下がっています。危険です
- 依存を治しましょう

日本語ディスプレイコピー（見出し・キャッチ）は句読点を使わず改行で割る・体言止めを基本とする（グローバル規約準拠）。

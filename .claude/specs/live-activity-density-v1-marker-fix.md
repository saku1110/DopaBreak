# Live Activityカード 行頭マーカーの縦位置修正（2026-08-29 オーナー指摘）

## オーナー指摘
「文字サイズ大きくしたのはいいけど、チェックリストのデザインが文字の中央に来てない」

フォント拡大（1件+5pt/2件+4pt/3件+2pt）後、目標行の行頭マーカー
（チェックボックス・ビュレット・記号）がテキストと縦にズレて見える。

## 対象マーカー（ios/WidgetsExtension/LockThemeLiveActivityView.swift）
- e1: 10×2ライムバー（HStack alignment: .firstTextBaseline — 拡大後のベースライン合わせが視覚的にズレる主因の可能性大）
- gaming: 12×12角枠チェックボックス
- note: 12×12角丸チェックボックス（回転付き）
- blueprint: Circle 8×8＋18×1ライン
- kpop: 縦バー5pt＋★ / kawaiiPink: ♥ / retroPop: ✽

## 修正方針（Fable決定）
1. **マーカーはテキストの1行目の視覚的中央（キャップハイト中心）に縦揃えする。**
   - 単行時: 行の縦中央揃えで可
   - 2行折返し時（e1の1〜2件・minHeight行）: 行全体の中央でなく**1行目**の中央に合わせる
     （`.firstTextBaseline` 揃え＋マーカー側に適切な `baselineOffset`/`alignmentGuide` 補正、等）
2. **マーカーサイズは目標フォントの拡大に比例させる。** 15pt基準の現行サイズ×(現在フォント/15)程度。
   線幅・spacing はデザイン印象を保つ範囲で微調整可。
3. テーマ構図・色・記号種は変更しない。カード160pt・水平16pt・既存全テストの制約は維持。

## 受け入れ条件
- 各テーマの目標行で、マーカー中心Yがテキスト1行目の視覚中央と一致して見える
- マーカーへlayoutAnchorを付与し、テストで「マーカー中心Yと目標テキスト1行目中心Y（単行フィクスチャではテキスト枠中心Y）の差が±2pt以内」を全テーマ×1/2/3件で検査する
- LockThemeLiveActivityViewTests 全件成功

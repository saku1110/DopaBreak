# ASA初回配信の全体診断（何がダメか）— 2026-09-20

**結論: 広告は機能している。落ちているのは「ストアページ」と「初回セッション」の2か所で、どちらも構造的な原因がある。** 商品ページ閲覧→DLは6.7〜7.9%（通常の1/3以下）、インストール当日の削除は4件中3件、無料ユーザーはブロックも一呼吸も一度も体験しないまま16画面目でペイウォールに着く。評価0件と、その原因であるレビュー依頼の到達不能がこれを固定している。

対象: Apple Search Ads 2026-09-12〜15（3市場・¥7,617・82タップ・16インストール・実ユーザーの試用1件）。データ: Apple Ads API、App Store Connect Analytics（9/13〜18・ONGOINGリクエスト 086127a1）、コード（1.0.1）、設計書、ライブのストアページ（ASC/CDN実取得）。

## 2. ストアページ（PV→DL 6.7%の原因）

事実（ASC APIとCDNで確認）:
- タイトル `DopaBreak − スマホ制限・スクリーンタイム` は検索語と一致（ここは良い）。
- **1枚目スクショの見出しが「SNSをブロックしない／開く前にひと呼吸」**。「スマホ制限」「アプリ制限」で検索してタップした人が最初に見る文が、探している機能の否定形。US「Don't block social media」・KR「SNS를 막지 않아요」も同じ構造。
- **実配信順がリポジトリの意図と違う**（ja・6.9インチ、ASC読み取り）: 01-breath → 02-lockscreen → 05-home → 06-intent → 04-lock-designs → 04-night → 07-reflection → **03-deepfocus（8枚目）** → 08-grayscale-home。制限意図に唯一応える「集中タイマーで完全ブロック／選んだアプリを止める」が横スクロール8枚目。5枚目はProバッジが9個並ぶテーマ一覧で、価値の前に「有料」の印象が来る。3市場とも同じ順。
- **評価0件**（JP/US/KR）。同じ検索結果に並ぶ競合は Blockin 19,231件・集中 132,831件・スタロック 8,060件・魚が育つ 15,958件。評価はストアフロント別で、バージョン更新では埋まらない。販売者名が個人名。
- 説明文の可視部（続きを読む前）に「制限」「ブロック」が出ない。App内課金一覧の先頭は `DopaBreak Pro（年額）¥4,980` で、7日無料はストア上に出ない。
- 無料トライアルの対象国はAPI上 **JP・KR・USのみ**（リリース証跡の「全テリトリー」は誤記）。英語圏キャンペーンのGB/CA/AU/NZ/IE/SGは試用なしの年額表示だった。

## 3. 初回セッション（当日削除75%・試用の伸び悩みの原因）

コードで確認した事実（file:line）:
1. **無料ユーザーはペイウォールまでに価値を一度も体験しない**。`OnboardingFlow.swift:2186-2192` の `shouldSkip(.blockSetup)` は非Proで常にtrue、しかも blockSetup はペイウォールの後ろ。`.permission` で自動化が発火しても `consumeAutomationVerificationOnly`（`OnboardingFlow.swift:2486`）で結果を捨て、一呼吸の画面は出ない。
2. **既定モードが standard（ブロックなし）**。`OnboardingFlow.swift:204`。設計書 `docs/07 §4`（L125）と §5（L413）は「デフォルト=Deep Focus・Recommended」。Deep Focus／夜だけ強化をタップすると9画面目で即ペイウォール（`onboardingModeGate`）。「制限」で来た人の第一希望が、価値を見る前に課金壁。
3. **無料には制限のフォールバックが無い**。シールド（ManagedSettings）は `usesShield` のPro専用モードだけ。無料の介入はショートカット自動化（アプリ外7手順・`AutomationGuideView.swift:643-687`）を自作しない限り一切起きない。
4. **オンボーディングの進捗が保存されない**。`OnboardingFlow.swift:186` の step は永続化なし。12画面目でショートカットAppへ離脱する設計なので、戻ってきたら welcome からやり直し。
5. **通知許可・ロック画面確認（画面を消させる）が価値体験の前**（13・14画面目）。
6. **レビュー依頼が到達不能**。`ReviewPromptPolicy.swift`: 開かなかった回数≥5・初回起動から3日・90日クールダウン・年3回、発火はwin画面のみ。自動化を自作して5回成功した人にしか出ない。評価0件はこの帰結。
7. **課金直後にDeep Focusがstandardへ戻る経路**。blockSetupで完了条件（Screen Time承認＋1アプリ選択＋保存成功）を満たせず「あとで」を押すと `persistStandardModeAndLeaveBlockSetup`（`OnboardingFlow.swift:2555`）が `.standard` を適用する。返金・低評価に直結。配信再開前に必ず直す。
8. **商品未取得時にペイウォールが空で出る**。`Product.products` 失敗時、価格「—」・CTA「年額プランを始める」のまま表示され、押して初めてエラー（`PaywallView.swift:515,705`）。
9. **計測が3属性のみ**（onboarding_completed／automation_verified／breathing_completed）。画面別の到達は端末内 `FunnelEventStore` に留まり外に出ない。どこで落ちたかが分からない状態。

## 4. 広告側（直すが、優先度は低い）

- スクリーンタイム／スクリーンタイム制限はTTR 3〜6%で意図不一致（機能の使い方検索）。停止。
- スマホ制限を¥150に上げてもCPTが¥92に上がっただけ。¥100へ。
- 転換した語は アプリ制限（CPI¥294）・スマホ制限アプリ（¥224）。
- 夜（21〜0時台）のタップがインストールに繋がりやすい（0時台 10タップ→4DL、昼13〜14時台 12→0）。再開時は18〜2時に絞る。
- KRサブタイトルに 차단／잠금／제한 が無く、앱차단 広告グループと不一致。
- 英語圏6か国は試用未設定のまま配信していた。

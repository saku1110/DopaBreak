## コピー設計メモ

- **ターゲットと認知段階**: アプリ内UI＝④商品自覚〜⑤最自覚（既に導入・使用中）。オンボ・LP・広告＝③解決策自覚〜④商品自覚（doc01 ICP：SNS依存を自覚するiPhoneユーザー20-39歳）
- **市場成熟度**: 4〜5（doc02b指摘通り。one sec/Opal/Forest等が乱立し「ブロックで止める」訴求は聞き飽きられている）→ ストレートな約束でなく、**メカニズムの優位性＋アイデンティティ**で語る
- **ビッグアイデア**: 既存戦略(doc01/02b)がすでに正しい方向を向いていた。「禁止しない。見た後の本音が、自然とSNSを減らす」。今回のMVPピボット（one sec方式採用）でこの思想が実装にようやく追いついた
- **使った顧客の言葉（doc02b §1に既存の想定語彙）**: 「気づいたら2時間溶けてた」「また時間溶かした」「意志が弱い自分を責めずに変わりたい」「完全ブロックは挫折した/続かない」。**未実施**: `mcp__grok__search_x`での実際の生声収集（doc01 §1で計画済み・XAI_API_KEY接続後に強化推奨）
- **主張と証拠の対応**: 「禁止しない」→ one sec方式で本人が選べる（開かずに戻る／時間を決めて開く）。「意志力不要」→ 一呼吸＋理由選択という小さな摩擦だけで強制はしない。「自然と減る」→ 利用後の正直な記録が本人の一貫性を作る（doc02b §4 一貫性の力）
- **法令チェック**: 「治る」「依存症」「脳を書き換える」等は禁止済み（doc09 §2）。今回の新コピーもこの規範に従う

## 1. ビッグアイデア（確定候補）

**「禁止しない。見た後の本音が、自然とSNSを減らす。」**

- one sec/Opal（ブロック型）との違いを一言で言う：**相手は「開けなくする」。DopaBreakは「開いた後の自分に、正直に聞く」**
- 実装との整合：一呼吸→理由→(開かず戻る／時間を決めて開く)→**見てどうだった？**（振り返り）→統計。ここまで全部実装済み
- 意志力訴求ゼロ（doc02b JTBD「責められずに、いつの間にか変えてほしい」と一致）

### 2c. オーナー提案「人生か、ドーパミンか」の展開（2026-07-08・採用検討）

**これは他の全案より強い。理由が3つ重なる:**

1. **実装のUI構造と1対1で一致する** — S-03「あなたの目標」（＝人生）を見せた直後にS-04「なんのために開く？」（＝ドーパミン欲求の理由）を問う設計。コピーが機能を後追いで説明するのでなく、機能そのものがコピーの体験化になっている
2. **アプリ名DopaBreakと語源が一致する** — Dopa(mine) + Break。「ドーパミンを断つ」という名前が、コピーの対立構造とそのまま重なる
3. **「気づき・自分で選べた」路線を"能動 vs 受動"の対比に格上げできる** — 「選ぶ」か「選ばれる」かの違いにすると、doc02b JTBD「意志が弱い自分を責めずに変わりたい」＝**無意識にドーパミンに"選ばれている"状態**からの解放、という核心のジョブを一言で説明できる

| # | コピー | 狙い |
|---|---|---|
| L1 | 人生を選ぶか<br>ドーパミンに選ばれるか | 能動/受動の対比が核心。JTBD「無意識に開く」の正体を言い当てる。**最推奨** |
| L2 | 人生か、ドーパミンか<br>選ぶのは、いつもあなた | L1をIと融合。やや説明的になる分、初見の理解は早い |
| L3 | 開く前に、聞かれる<br>人生か、ドーパミンか | 実装のS-03→S-04の体験を予告する導入コピー向け（LP/オンボ向き） |
| L4 | 今日は、人生の日？<br>それとも、ドーパミンの日？ | 問いかけ型。日次の使用シーンに寄せた口語 |

**推奨: L1を主コピー、サブコピーはL1の思想を実装フローで裏付ける構成。**

- 「禁止しない。ただ、毎回聞くだけ。人生か、ドーパミンか」← ブロック型との差別化もここで回収

## 4. 「取り戻す」代替表現の方向性

**判定**: 「取り戻す」は"失ったものを取り返す"という強い喪失フレーム。doc02bの思想（禁止しない・責めない・気づきベース）とは温度がズレている。ビッグアイデア「本音が自然と減らす」に合わせ、**「気づき」「自分で選んだ」を主語にした表現**へ統一する。

| 文脈 | 旧（取り戻す系） | 新（気づき・自己決定系） |
|---|---|---|
| 勝ち画面 | （取り戻した時間は未使用だったが念のため） | 開かなかった<br>今日も、自分で選べた |
| 週次レポート見出し | 取り戻した時間 | 気づけた回数 |
| ペイウォール旧文言 | この設定で、無意識にSNSを開く瞬間をDopaBreakが止めます | この設定で、開く前の一呼吸が増えます |
| 統計指標ラベル | 開かずに我慢 | 開かずに戻れた（「我慢」も意志力訴求なので置換） |

「我慢」も同じ理由で置換対象とした（我慢=意志力に頼る言葉。DopaBreakの差別化は「意志力不要」なので矛盾する）。

# UI文言集（正本）— DopaBreak

作成: 2026-07-02（オーナー指摘「介入は内部用語」「アプリを守るは意味不明」を受けて新設）
**役割: ユーザーに見えるすべての文言はこのドキュメントが正本。実装（Fable/Codex/Opus）はここから転記のみ。新画面を実装するときは、先にここへ文言を追加してから実装する。**

---

## 0. 文言の原則

DopaBreakは **SNS依存・ドーパミン中毒を軽減するアプリ**。文言は「自分の悩み（無意識にSNSを開いて時間を溶かす）が解決できる」と一読でわかる、具体的で自然な日本語にする。

| 層 | 語彙 |
| --- | --- |
| **問題の言葉**（ユーザーの自己認識） | SNS依存 / ドーパミン中毒 / 無意識に開く / 時間を溶かす / ダラダラ見て後悔 |
| **解決の言葉**（機能の説明） | 止める（止めるアプリ・止める強さ）/ 開こうとした / 開かずに我慢 / 一呼吸 / 見たあとの気持ち / 取り戻した時間 / 戻る先（＝目標） |
| **禁止** | ①内部用語: 介入・再介入・シールド・セッション・リフレクション（UIでは「見たあとの振り返り」）②医療表現: 治療・治る・依存症の診断 ③対象が曖昧な表現: **「アプリを守る」「あなたを守る」**（何を守るのか不明）④過度な口語・スラング |

- 見出し・短い表示文: 句読点を使わない（改行と体言止め。グローバル規則）。本文・説明文: 通常の句読点OK。
- トーン: 責めない・禁止しない・命令しない。「〜しましょう」より事実と選択肢の提示。
- オンボーディングの全文言は [doc07](./07_onboarding_design_lifefocus.md)、通知/Live Activity文言は [doc06 §9](./06_screen_design.md)、ペイウォールは本書§5。

### 2026-07-18 ペイウォール見出し・機能行の確定改訂（オーナー承認）

見出しは多段検証（コールドリード＋敵対的判定・4ラウンド）で現行案の欠陥（仕組み誤読→ブロッカー期待の返金リスク）を確認し差し替え。2行目はオーナー最終修正（「一拍おく」は響かない→「開く前にブレーキ」・読点なし）。

| 対象 | 旧（実装現行） | 新（確定） |
| --- | --- | --- |
| 見出し | その 38 日を、人生に使う（38は固定値・1行） | **「あと5分だけ」が年{N}日**<br>**開く前にブレーキ**（2行構成） |
| {N}の値 | 固定38 | SelfCheck回答からのLossEstimator推計値。未回答時は既定バケット「2-4時間」＝38。固定値のハードコード禁止（景表法上、個人推計である前提が必要） |
| 機能行3 | 詳細な統計と継続記録 | **記録を全期間さかのぼれる**（EntitlementGate.statsDays: Free=1日/Pro=無制限 に対応する実差分） |
| 機能行4 | 複数の目標とモード | **目標を何個でも追加できる**（上表2026-07-02確定文言と統一） |
| O-08b リード（転記） | この設定で、無意識にSNSを開く瞬間をDopaBreakが止めます。 | **この設定で、開く前の一呼吸が増えます。**（能力の過大表現を排除。doc07 §5 2026-07-18改訂表が正） |

- サブコピー（「無意識に消える時間を、あなたが選んだ目標へ戻します。」）は現状維持。差し替え案はオーナー確認待ちのため本改訂に含めない。
- 見出しの数字アクセント（accent色）は{N}の数字部分に適用。2行化に伴いlineLimit(1)は撤廃する。

### 5c. ペイウォール2段化＋月換算ヒーロー表示の文言（2026-07-21 オーナー承認・doc06 §10改訂と対）

プランカードは年額・月額の2枚。買い切りはSettings「アカウント/課金」へ移設。価格はStoreKit実価格から動的生成（ハードコード禁止）。**商品未取得時は「—」プレースホルダ表示とし、具体額のフォールバック文字列は禁止**（非日本ストアフロントでの誤価格表示＝審査リスクのため。2026-07-21 Codexレビュー指摘で確定）。買い切り行は entitlement解決済みかつFree の場合のみ表示。

| 要素 | 文言（テンプレート） | 備考 |
| --- | --- | --- |
| 年額カード ヒーロー価格 | {年額price÷12}/月 | 例: 415円/月。大きく表示 |
| 年額カード 総額行 | 年間{年額price}を一括請求 | 月換算の直下・**可読サイズ必須**（審査3.1.2/景表法。極小表示禁止） |
| 年額カード 補足 | 7日間無料（トライアル対象者のみ・introductoryOfferから導出） | 総額行と「・」区切り可 |
| 月額カード ヒーロー価格 | {月額price}/月 | 例: 980円/月 |
| 年額法務（トライアル対象・動的） | {N}日間の無料期間終了後、年額{価格}で自動更新。いつでも解約できます。購入はApple IDに請求されます | §16の動的法務方針と統一・**請求総額を法務文言にも明記** |
| Settings 買い切り行 | 買い切りプラン {価格} | Free時のみ表示。タップで購入フロー |

目標を決めただけでは、実際にロック画面へ出ているかをユーザーが確認できない。iOSは**ユーザーが最初にロック画面でLive Activityを見た時点で許可を聞く**ため、確認導線がないと「許可しない」を押されたまま気づかれない。目標保存の直後に「掲出 → サイドボタンで確認 → 許可」の順で見せる。

| アイブロウ | LOCK SCREEN |

| ボタン | 設定を開く / もう一度出す / 完了 / あとで（オンボは 次へ / あとで） |

- プレビューは実際のLive Activityと同じ体裁（見出し「あなたの目標」＋実績行）。出せていないときは薄く落として「いま出ていない」ことを示す。
- **原因で案内を変える**。端末側オフ＝設定の場所＋「設定を開く」／許可はあるのに出せなかった＝「もう一度出す」。オフでもないのに設定変更を促さない。
- 「確認済み」へは、実際に一度アプリを離れて戻り、かつ掲出が続いているときだけ進む（自己申告ボタンは置かない）。
- **確認できたときだけ完了として記録する**。見ないまま「次へ」「あとで」で抜けた人には、次に目標を追加したときもう一度出す。

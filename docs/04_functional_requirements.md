# 機能要件

作成日: 2026-06-27 / 改訂: 2026-07-12（目的確認先行・目的別介入・実測値のみのHome表示を反映）

## 1. 前提

MVPはiOSネイティブアプリとして設計する。対象OSは初期リリース時点でiOS 17以上を推奨する。Screen Time API、WidgetKit、StoreKit 2を利用する。

## 5. 権限制約

- Screen Time API利用には適切なentitlement/capability設定が必要。
- FamilyActivityPickerで選択したアプリ/カテゴリ/Webはopaque tokenとして扱う。
- カスタムシールドで表示できるUIにはiOS側の制約がある。
- ウィジェット更新頻度はOSに制御されるため、リアルタイム更新を前提にしない。
- 他社アプリを閉じた瞬間のイベントは取得できないため、利用後リフレクションは選択時間終了、再シールド、アプリ復帰、通知で近似する。

## 6. App Review注意事項

1. 「依存症を治す」と書かない。
2. 「願いが叶う」と保証しない。
3. Screen Time API利用理由を明確にする。
4. 収集データをPrivacy Nutrition Labelと一致させる。
5. サブスク価格と更新条件を明確に表示する。

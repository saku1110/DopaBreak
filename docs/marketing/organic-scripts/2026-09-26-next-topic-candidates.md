# 次のネタ候補（男性主人公で作る1本・2026-09-26）

- 依頼: 「2つの動画を作ったので、次のネタの企画案をいくつか提案して。その中で良いものを男性で作る」
- 前提: 実写風の不気味な誇張。主人公は人間1人（男性）。最後のシーンに英語でプロフィール誘導。前作の浮くスマホ（腕2本・通知アイコン3つ）と「誘惑中＝体調が悪い顔／触ると見開いて充血」はシリーズの決まりとして続ける
- 組み方（オーナー指摘で修正）: 前作2本と同じく、複数シーンで時間が進み、スマホの先で失っているもの（人・予定・目標・時間）まで広がる流れで組む

## 却下した初回案（2026-09-26）

レンジの90秒・トイレ・時間確認・ジムの休憩・震えの錯覚の5本。オーナー判断「1つのシーンにするには内容が薄すぎるし共感できない」。場所1か所・1行動・1ギャグの小ネタで、見た人の生活に重なる損失がなかった。

## 候補4本

### 1. 人が消えていく（The people who faded）
- 芯: スマホを見ている間に、大事な人が自分の人生から消えていく
- 流れ: 金曜のデート（向かいで彼女が話す。机の上の浮くスマホが彼をつつく）→ スマホを取った瞬間に目が充血し、彼女の体が少し透けて声がこもる → 日曜の実家（父の昔話の最中に机の下でスクロール。父が薄くなる）→ 友人の誕生日（乾杯の輪から外れて画面を見る。友人が輪郭だけになる）→ 繰り返すたびに消え方が速くなる → 深夜に顔を上げると部屋の椅子が全部空いていて、グループのやり取りも止まっている → 浮くスマホだけが彼の肩に手を置く → プロフィール誘導
- 知らなかった事実: 恋人がいる人の7割が「スマホが相手との時間の邪魔になっている」と答え、邪魔されるほど関係の満足度が下がった（Roberts・David 2016／Baylor大学）
- 見せ場: 話している彼女が透けていくのに、彼は気づかずスクロールしている
- 男性で作る理由: 「彼氏がスマホばかり見ている」と感じる恋人側が送りやすい。男性本人も自分を重ねやすい

### 2. 1年の早送り（One year）
- 芯: 毎年書く同じ目標が、スマホの向こうで今年も終わる
- 流れ: 1月1日に冷蔵庫へ今年の目標を貼る（ギター・体を鍛える・自分の事業）→ 浮くスマホが来て「1分だけ」→ 窓の外が雪→桜→夏→紅葉と進み、彼はソファに沈んで飲み込まれていく。ひげが伸びる → ギターにほこりとクモの巣、シューズは箱のまま → 友人の誘いの通知を親指が払いのける。スマホはつやつやに、彼は青白く → 12月31日の花火で顔を上げ、黄ばんだ目標の紙の「2026」を消して「2027」と書き直す → プロフィール誘導
- 知らなかった事実: 米国人のSNSは1日平均2時間9分で、1年に直すと約33日（DataReportal 2026）。人は自分の使用量を実際の約半分に見積もる（Andrews ほか 2015）
- 見せ場: 同じ紙の年号だけ書き換える
- 前作とのつながり: 電車編（数分）→ 一日編（1日）→ 今回（1年）と時間の単位が大きくなる。目標を見せるDopaBreakの強みに一番近い

### 3. 消えた週末（The weekend）
- 芯: 休んだはずなのに、月曜の方が疲れている
- 流れ: 金曜の夕方に週末の予定を付箋に書く（山・自転車の修理・友達）→ 土曜の朝にベッドで「5分だけ」。天井の日差しが動いて昼になる → 付箋が1枚ずつ冷蔵庫から落ち、彼はソファに沈む → 土曜の夜、画面の中で友人たちが山頂で笑っている → 日曜はソファが体を包み、自転車がさびる → 月曜の朝、同僚に「週末どうだった？」と聞かれて答えられない → プロフィール誘導
- 知らなかった事実: 受け身でSNSを眺めると、その後の気分が下がった。原因は他人への羨ましさだった（Verduyn ほか 2015・実験）
- 見せ場: 行くはずだった山の写真を、友人の投稿としてベッドで眺める

### 4. 画面越しの人生（A life through the screen）
- 芯: 人生の大事な場面を、いつも画面越しに見ている
- 流れ（少年から老人まで同じ人物）: 子どもの誕生日にケーキの前でタブレット → 10代のライブで撮影だけしてステージを見ない → 友人の結婚式でスピーチ中に通知を見る → 父の70歳の誕生日で話しかけられても画面を見ている → 父の席が空いている → 老人になった彼が顔を上げると誰もいない。浮くスマホも古びている → プロフィール誘導
- 知らなかった事実: 米国平均の1日2時間9分を60年続けると、約5年分になる（DataReportal 2026から計算）
- 見せ場: 父の空いた席
- 注意: 重い。年齢ごとに同じ顔を保つ手間がかかる

## オーナー判断（2026-09-26）

1（人が消えていく）を男性主人公で制作。2・3・4は却下。今後のネタは、まずドーパミン中毒・SNS中毒のアンケートや研究からヒントを得て作る。

## おすすめ

1（人が消えていく）。前作2本は「体」と「一日」だったので、「人間関係」は新しい広がりになる。人が透けていく絵は1秒で意味が分かり、見た人が自分の恋人・家族・友人を重ねられる。恋人側が送ることで広がりやすく、男性主人公である意味もある。DopaBreakの強み（目標）に寄せたいなら2。

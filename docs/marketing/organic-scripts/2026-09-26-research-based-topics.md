- 組み方: 前作と同じく複数シーンで時間が進み、失うもの（人・思い出・時間・お金）まで広がる流れ。シリーズの決まり（浮くスマホ・誘惑中はクマの顔・触ると充血）は続ける

## A. 楽しかったのはスマホだけ（Your phone had a great year）

### 芯
一番楽しいはずの場所で、楽しんでいるのはスマホの方。彼は画面越しにしか見ていない。年末、思い出を持っているのはスマホだけ。

### 誇張装置
**立場の入れ替わり**。どの場所でも、浮くスマホの方がその場を満喫している（ライブで腕を振り上げて歌う・映画に夢中でポップコーンを抱える・家族と一緒に大笑いする・ビーチで日光浴する）。彼はそのスマホを見つめているだけ。

### 流れ（30秒・約16コマ）
1. **ライブ**（土曜の夜）: 大好きなバンドのサビで観客が合唱する。彼だけクマのある顔で落ち着かない。肩の浮くスマホがつつく
2. スマホを掲げて撮影する（目が充血）。見ているのは画面の中の小さなステージ。隣では浮くスマホが腕を振り上げて歌っている
3. **映画館**: 物語の山場で客席が息をのむ。暗い客席で彼の顔だけが青く光り、前の列の人が振り返る。浮くスマホはポップコーンを抱えてスクリーンに夢中
4. **家族の団らん**（感謝祭の食卓）: 家族が大笑いする。彼は机の下で画面を見ている。浮くスマホは家族と一緒に笑い、七面鳥を取り分けてもらっている
5. **休暇のビーチ**: 夕焼け。彼は海に背を向けて上司のメールに返信する。浮くスマホはサングラスで日光浴をしている
6. **花火**（7月4日）: 彼は花火を撮っていて、画面越しにしか見ていない。浮くスマホは空を見上げて見とれている
7. **年末**: 友人に「今年どうだった？」と聞かれ、彼は何も思い出せない。カメラロールには数千枚の写真と動画があるが、どれも開いたことがない
8. 浮くスマホの画面に、この1年の楽しかった場面が次々に流れる。覚えているのはスマホだけ。彼は充血した目でそれを見つめる
9. プロフィール誘導（シリーズ共通）

### 知らなかった事実（テロップ候補）
- ライブを撮影していて演奏の一部を見逃した人は41%。撮った動画を見返さない人は25%。1公演で平均12分以上を画面越しに見ている（英国1,100人・Compare and Recycle 2025・1-10）
- 写真を撮ると、撮らなかったものより記憶に残りにくい。撮ってすぐ消える写真でも同じだった（Soares・Storm 2018・1-19）
- スマホで撮った写真の7割は二度と見返されない（米英仏独8,000人・Popsa 2026・1-15）
- 家族の食事中、親の77.6%・子の68.7%が画面を見ていた（JAMA Pediatrics 2026・1-1）
- 有給休暇中でも86%が上司のメールを確認している（Harris Poll 2023・1-14）

### 見せ場
- 笑う: ライブで浮くスマホの方がノリノリで歌っている
- 息を止める: 年末、思い出がスマホの中にしかない
- 送りたくなる: 「ライブで撮影ばかりしている友達」に送れる

### 追加で提案する場所（オーナー提示のライブ・映画館・家族の団らん以外）
| 場所 | 数字 | 出典 |
|---|---|---|
| 休暇のビーチ | 有給休暇中でも86%が上司のメールを確認 | Harris Poll 2023（1-14） |
| 花火・夕焼け | 撮った写真の7割は見返されない | Popsa 2026（1-15） |
| スポーツ観戦 | 生観戦中に82%がスマホを使う。得点の瞬間を見逃す | Deloitte 2023（1-11） |
| 友人の結婚式 | ゲストの27%が式の最中にSNSへ投稿（2017年） | WeddingWire（1-16） |
| 家で映画 | 76%が映画やTVを見ながら別の画面を使う | YouGov 2026（1-9） |

## B. スマホ以外のドーパミン中毒（今後の候補）

どれも複数シーンで時間が進む形。数字は根拠ファイルの番号つき。

### B1. 注文した記憶がない（Late-night cart）
- 流れ: 深夜1時、SNSの広告から通販のカートへ → 翌朝から段ボールが毎日届く → 部屋が箱で埋まり、玄関のドアが開かなくなる → 注文した記憶のない確認メールで目が覚める → 月末の請求を見て青ざめ、その夜また深夜1時にカートを開く
- 誇張: 箱が勝手に増えていく。親指が「今すぐ買う」ボタンにくっついて離れない
- 事実: 深夜のネット通販の75%は計画外。13%は注文した記憶のない確認メールで朝目が覚めた。21%はSNSのスクロールがきっかけ（CouponFollow 2026・3-2）

### B2. 次のエピソードまで5秒（Next episode in 5）
- 流れ: 金曜の夜「1話だけ」 → 自動再生のカウントダウンを止められない → ソファが体を飲み込み、窓の外が朝・昼・夜と何周もする → 日曜の深夜に我に返る → 月曜の会議で寝落ちする
- 誇張: 画面のカウントダウンの数字が画面から出てきて、立ち上がろうとする彼を押し戻す
- 事実: 一気見のせいで睡眠を失った人は91%（AASM 2023・3-10）

### B3. 負けを取り戻す（Chasing it back）
- 流れ: 友人と試合を観る → 彼だけオッズの画面を見ている → 負けを取り戻そうと賭け金を上げる → 得点の歓声の中で彼だけ青ざめる → 月末、口座の残高が赤く光る → 翌週も同じ
- 誇張: 瞳の中にオッズの数字が流れる。財布から紙幣が砂のようにこぼれ続ける
- 事実: 賭ける人の60%が負けを取り戻そうと賭け金を上げた（前年52%）。18〜49歳の男性の52%がオンラインの賭け口座を持つ（Siena・St. Bonaventure 2026・3-3）
- 注意: 男性に偏った題材。依存症の扱いなので、笑いより怖さで見せる

### B4. 午後3時の缶（The 3 PM can）
- 流れ: 朝のコーヒー → 昼のエナジードリンク → 午後3時に2本目 → 夜眠れずスマホ → 翌朝はもっと多く飲む。1週間で机の缶が積み上がって壁になる
- 誇張: 目が見開いたまま閉じない。体が細かく震え続ける
- 事実: Z世代の53%が2週間に1回以上エナジードリンクを飲む（EY 2026・3-6）。成人の66%が昨日コーヒーを飲み、飲む人は1日平均3杯（NCA 2025・3-5）

### B5. あと1戦（One more match）
- 流れ: 夜11時「あと1戦」 → 窓の外が白む → 仕事中も手がコントローラーの形に固まっている → 週末また夜が明ける
- 誇張: 手がコントローラーの形から戻らない
- 事実: 18〜34歳の72%がゲームで夜更かしした（AASM 2019・3-11・古い）

### 候補から外したもの
- 食べ物（超加工食品）: 体型を笑う表現になりやすい。扱うなら体型でなく「冷蔵庫を開けて閉めてアプリを開く」の行動側で描く
- マッチングアプリ疲れ（78%）: 一次ページが取れず二次記事のみ。利用者に対象が絞られる

## おすすめの順番

1. **A（楽しかったのはスマホだけ）**: オーナーが挙げた3場所に、数字のある2場所（ビーチ・花火）を足せる。「撮ると記憶に残りにくい」は知らない人が多く、見終わった後に人に話したくなる事実
2. **B1（注文した記憶がない）**: スマホ以外の1本目。「13%が注文した記憶のない確認メールで目覚めた」が1秒で伝わり、箱が部屋を埋める絵も強い
3. B2（一気見）・B3（賭け）: 題材として強いが、B3は男性に偏り扱いが重い

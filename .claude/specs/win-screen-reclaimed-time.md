# 開かなかった画面: 取り戻した時間を主役にする

決定日: 2026-08-31（オーナー指示）

## 解決する問題

1. **不具合**: 目標が `flow.goals.first` で先頭1件しか出ていない（InterventionFlowView.swift の winScreen）。
2. **体験**: 「開かなくてよかった」と思える要素がない。原因は3つ。
   - 「今日N回目」が**開こうとした回数**で、獲得ではなく羞恥を告げている
   - 回数2種（開かなかった／開こうとした）は我慢の記録で、手に入った実感がない
   - 見出し「そのぶん自分の時間が残った」が抽象的で、いくら残ったか分からない
3. **構造的な欠落**: ホームには「SNSを開かずに取り戻した時間」が累計・日数換算つきで既にある
   （2026-08-25実装）。しかし**増えたその瞬間に見せていない**。報酬が行動の直後に来ていない。

## 採用方針

開かなかった画面の主役を「回数」から「取り戻した時間」へ移す。ホームの貯金表示と同じ書式を使い、
増えた瞬間に増分と累計を見せる。目標はその時間の使いみちとして全件並べる。

## 実装

### A. 取り戻した時間をヒーローにする
- 表示は上から「増分」「ラベル」「累計＋換算」の順。
```
  ＋8分                    増分（大きく・アクセント色・カウントアップ）
取り戻した時間               ラベル
累計 2時間14分  3日分        ホームと同じ書式
```
- **増分は保存済みの値を読む**。`insertCancelledAttempt` が確定させた `reclaimedSeconds` を使い、
  画面側で `ReclaimedTimeEstimator` を再計算しない（二重計算で値がずれるため）。
- 累計は `statsService.reclaimedSecondsAllTime()`。
- 書式は HomeView の既存ヘルパー（`home.reclaimed.*` / `home.hero.lifetime.*_equiv`）を共通化して再利用する。
  重複実装しない。ホームと表記がずれると同じ貯金に見えない。
- 数字の変化には `.contentTransition(.numericText())` を使い、ホームと挙動を揃える。
- 推定であることが分かる根拠表記を1行入れる（ホームの `home.hero.basis` と同じ考え方）。
  断定表現にしない。

### B. 目標を「使いみち」として全件出す
- `flow.goals.first` を廃止し全件表示する。
- カード見出しを `intervention.goal.eyebrow`（"YOUR GOAL"）から
  新キー「この時間の使いみち」へ差し替える。装飾の英語ラベルは使わない。
- オンボーディング「取り戻した時間で何をしたいですか？」の回収にあたる。
- **5件で画面が溢れないこと**を実描画で確認する。溢れる場合は件数に応じて文字サイズと行間を落とす
  （ロック画面と同じ考え方）。目標を隠す方向で逃げない。

### C. 回数の扱いを変える
- 「今日N回目」（開こうとした回数）を**廃止**する。
- 2カラムのメトリクスカード（開かなかった／開こうとした）を**廃止**する。
- 代わりに小さく1行だけ「今日 N回 開かなかった」を置く。成功した回数のみ。
- 統計画面は変更しない（両方の記録は残す）。

### D. 見出しの廃止
- `intervention.success.title`（「開かずにすんだ\nそのぶん自分の時間が残った"）を廃止する。
  数字が主役になるため見出しと競合する。コード内の `\n` ハードコードもここで解消する。

### モーション
- 増分のカウントアップと成功の触覚を入れる。
- spring値・持続時間・触覚の種類は `mobile-motion` スキルから引く。記憶で数値を決めない。

## 制約（変更禁止）

- 取り戻した時間は推定値。「◯分節約できます」等の効果断定へ言い換えない（2026-08-17の制約）。
- 表示コピーに読点を入れない。句点を打たない。体言止めを基本にする。
- 装飾用の英語eyebrowを使わない。内部用語（介入・シールド等）をUIに出さない。
- Swift側 defaultValue と Localizable.xcstrings を完全一致させ、ja/en/ko を揃える。
- 統計のデータモデル・集計を変更しない。

### E. 節目のクラッカー演出（オーナー指示で採用）

累計が節目を**初めて超えた回だけ**、通常より強い祝いを出す。毎回同じ報酬は必ず慣れるため、
たまに来る強い報酬で持続させる。

- **節目**: 1時間 / 6時間 / 12時間 / 以降は日数換算が1つ上がるたび（1日分・2日分・3日分…）。
  日数が上がる間隔は24時間ぶんの蓄積が必要なので、後半になるほど自然に希少になる。
- **一度だけ**発火させる。到達済みの最大節目を永続化し、再表示・再起動で二重に出さない。
  保存先は SettingsStore（resettable）とし、ローカルデータ削除で初期化されること。
- **演出**: クラッカー（紙吹雪）を画面上部から散らす。
  - 依存パッケージを足さない。SwiftUIの `TimelineView` + `Canvas` で自前実装する
    （一人運用のため外部ライブラリを増やさない）。
  - 2〜3秒で自然に消える。閉じるボタンを覆わない。連打で多重発火させない。
  - **Reduce Motion 有効時は紙吹雪を出さない**。代わりに静的な祝いの表示へ落とす（HIG要件）。
  - 触覚は通常時より強くする（通常=success相当、節目=より強いパターン）。
- **文言**: 単位の翻訳を主役にする。「2時間14分」より「まる1日ぶん」のほうが体に来る。
  例（読点・句点なし・体言止め）: 「まる1日ぶん 取り戻した」。
  1時間・6時間・12時間の節目は日数にならないため、時間のまま出す。
- ホームの日数換算表示と数字がずれないこと。同じ換算ロジックを共有する。
